# M0 Checkpoint — GitHub Pages 遊戲骨架

## 完成狀態

M0 的程式骨架已能通過型別檢查、確定性測試與正式建置。畫面直接進入遊戲大地圖，不是宣傳首頁。

目前可操作內容：

- 世界時間在 Web Worker 中持續前進。
- 地圖以 45° 等距菱形棋盤呈現，可拖曳、游標定點縮放及選取格位據點。
- 草地、農地、森林、丘陵、山地、水域、河流與道路均落在連續地格上。
- 可對非首都據點派出 M0 測試斥候。
- 斥候抵達會成為排程事件、揭露地點並產生報告。
- 四項資源按世界時間累積。
- 狀態自動保存至 IndexedDB。
- 關閉後再次開啟會進行基礎離線追算並顯示摘要。
- 六個文明與代表兵種已使用穩定內容 ID 建檔。
- PWA 與 GitHub Pages 自動部署設定已建立。

## 已驗證

- `npm run typecheck` 通過。
- 3 個測試檔、5 項測試全部通過。
- 一次推進與分段推進會得到相同世界 hash。
- 斥候事件在線分段及離線一次追算結果相同。
- `npm run build` 可產生完整 `dist`、manifest 與 Service Worker。
- GitHub Actions 情境下會自動使用 `/<repository-name>/` 路徑。
- Vite 已明確設定跨平台 `@` 路徑別名，Windows 開發伺服器可正確解析 `@/hooks` 等來源檔。
- 等距投影已驗證兩條棋盤軸皆正確投射，所有 M0 據點均位於地圖界內。

## M0 尚未包含

- 正式新戰役／文明選擇流程。
- 多存檔、輪替備份、手動匯出與匯入。
- 多分頁單一寫入鎖。
- 完整城市建築、研究、軍隊、外交、AI 與戰鬥。
- 正式地圖生成器及 80～120 個節點。
- 最終美術、音效及平衡數值。

這些屬於 M1 以後，不應誤認為已完成。
