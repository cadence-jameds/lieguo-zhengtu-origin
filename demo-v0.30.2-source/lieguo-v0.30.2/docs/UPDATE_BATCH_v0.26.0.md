# 本輪更新驗證（3 項）

1. **高低地勢與地域配置**：低地、平地、丘陵、高地為連續坡面，格線依地面變形。城市、選取、座標定位、行軍路線和道路對齊地面。河谷低、主流沿下游下降、湖泊水平。森林依濕潤程度、距水、坡度及海拔分布，丘陵可覆有樹木；高處、陡坡、乾燥區樹木較稀。森林樹冠／樹幹與圓缓丘陵坡脊可區分。只有現有丘陵／森林等地形效果，不疊加額外高度戰力。
2. **資源字級**：糧、木、石、金等野外文字比城市文明文字小15%；描邊和陰影保留。等級標籤不縮小。
3. **256據點**：64區域平均4個、約3～5個；糧77／木64／石51／金26／盜賊38。沿用等級、獎勵與30～75世界分鐘冷卻。

## 舊存檔

沿用既有河道、水域、城市、已出發行軍路徑與抵達時間。新的植被與地形分類會影響後續新下達命令所使用的既有地形效果。384槽位縮至256時優先保留已有部隊參與的目標；若某類目標超額且有部隊未返回，暫保留該遭遇直到行動完成，再於下一次世界分鐘移除。此類目標不接受新出征、不再重生。野外情報在遷移時失效，需重新偵察；歷史戰報保留。

## 驗證與限制

- 自動驗證不同河道版本與縮放下的投影／點選對位、鄰格共用頂點、平滑坡面、丘陵森林共存、湖泊水平、下游高程、資源字級比例。
- 驗證384轉256後行軍目標與抵達時間、回程及再存讀檔。
- 既有功能與後期存檔6小時推進回歸。
- 以遊戲實際地形繪製程式輸出近景與遠景檢視；完整遊戲瀏覽器預覽受連線限制，手機／桌面實機觸控和整體UI仍待驗收。
