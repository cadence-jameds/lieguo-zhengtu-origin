## 1. 新戰役顯示上一個存檔的離線戰報

- 回報：選擇「開始新遊戲」後，仍播報上一個存檔的戰報。
- 原始碼定位：`useGame.ts` 在首頁啟動時即載入舊存檔，將 `offline` 摘要留在 React 狀態。`GameApp.tsx` 的 `newCampaign` 直接進入遊戲並傳送 `start`，沒有清除摘要。Worker 切換戰役時也未清除 `away`，且離線消息未攜帶戰役識別，舊摘要可能在新戰役畫面顯示。
- 預定修正：切換新戰役／匯入／回復時重設舊摘要與離線起點；以戰役識別及切換狀態隔離延遲返回的消息。新戰役成功建立後才顯示新戰役畫面。
- 驗收：舊存檔有離線戰報時，從首頁開新局不顯示舊摘要；載入原進度仍正常顯示該戰役摘要；切到背景再開新局、匯入或回復均不串用消息；建立失敗仍能保留原進度。
- 狀態：已確認程式存在狀態未重設的路徑，待本批確認後實作。

## 2. 建築浮窗可點背景關閉

- 需求：選擇建築及建築操作浮窗，點擊視窗外的遮罩／背景即可關閉，不強制點右上角 X；保留 X。
- 互動：窗內點擊、捲動及選取不觸發關閉；從窗內拖曳到窗外不算點背景。桌機滑鼠與手機觸控均適用。
- 範圍：只退出建築操作介面；不取消已下達的施工命令、不拆除建築，且點背景不穿透觸發下層地塊操作。
- 狀態：待本批確認後實作。


## 3. 世界地圖預選與直接選格建城

滑鼠移動顯示細線預選框，與正式選取區分；取消地圖建城模式按鈕。點合法空格開成本及確認浮窗，非法格說明原因；手機直接點格子。

## 4. AI 與玩家共用新手保護

AI 領主同樣受保護，期限與玩家一致；主動對其他領主下敵對命令（含偵察）即解除，取消命令不恢復。非國家野外據點除外。保護阻止玩家與 AI 攻擊受保護領主；護罩依實際狀態顯示。
