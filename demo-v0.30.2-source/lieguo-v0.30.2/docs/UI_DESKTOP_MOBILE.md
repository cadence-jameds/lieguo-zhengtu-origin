# 電腦與手機介面（2026-09-07）

電腦為主要操作介面，手機為獨立的輔助版面；共用遊戲引擎、命令驗證與同一瀏覽器的存檔。跨裝置仍須匯出／匯入，不會自動雲端同步。

- 電腦保留三欄：主導覽、地圖／城市工作區、據點與戰役資訊。
- 手機在寬度 760px 以下，或觸控裝置寬度 1100px 以下，自動使用手機版面。旋轉或調整視窗時關閉暫時面板，保留目前功能與戰役。
- 手機固定底部五入口：地圖、城市、軍隊、戰報、更多。更多包含研究、外交、帝國方針、設定、說明、建國方略與勝利進度。
- 據點清單由地圖上方「據點」開啟；地圖或清單選取目標後開啟底部資訊面板。開始出兵或進入城市時關閉資訊面板。
- 資源始終可見；駐軍兵力列可左右滑動。城市切換在主區域上方。
- 手機建築、出兵、存檔確認沿用原生模態對話框，改為底部面板；支援焦點限制與關閉按鈕。
- 手機單指平移、雙指縮放；縮放後抬指與取消觸控不會觸發選城。電腦保留滑鼠、滾輪與鍵盤操作。
- 支援動態視窗高度、瀏海與底部安全區；表單輸入採 16px 字體。手機橫向壓縮頂列，地圖工具改為橫排。

驗證：TypeScript 與正式建置通過。未執行真機、瀏覽器視覺或觸控端到端驗收；不因此將 M6 手動驗收標記為完成。此次未修改遊戲引擎、存檔格式與數值。

真機待驗收：直向 360／390／430px 與橫向手機；點空地建設、建築升級／拆除、出兵數量輸入與鍵盤、據點搜尋、雙指縮放後無誤選、更多功能可達、存檔匯入匯出、旋轉時無遮罩殘留；電腦 1280／1440px 三欄與滑鼠操作。
