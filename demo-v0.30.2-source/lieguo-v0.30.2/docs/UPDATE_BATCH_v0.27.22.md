# 列國征途 v0.27.22 更新清單

日期：2026-09-28。接續 v0.27.21 的 Sites 來源與既有玩家存檔。

- XY 定位縮成 X、Y、前往同列。XY 與最愛浮窗初次置中、標題列可拖曳，分別記住關閉前位置；視窗改變尺寸時限制在地圖內。
- 最愛列表的糧、木、石、金標頭對齊各列數字。城內與城郊建築按鈕關閉手機瀏覽器藍色點按提示，保留鍵盤焦點輪廓。
- 調整城堡、城市中心、軍事與公共建築的佔位尺寸；城郊中央城市縮圖略放大，並微移兩處靠近其他資源地的建築位置。
- 時代晉升與科技研發在頂部各有獨立進度條及配色；同時進行時分兩列，完成後各自消失。經典、暗色、亮色主題使用相應對比色。
- 同一世界小時的跨城建設、募兵、總督與商隊抵達歸入一則摘要，展開依城市檢視，顯示已入庫物資與滿倉返程或捨棄的數量；重大戰鬥維持獨立紀錄。舊版已產生的戰報保留原樣。
- 世界地圖的地形只在 0～255 可選範圍外保留八格緩衝；森林樹木增大、以固定種子安排一至三棵並容許樹冠跨格。
- 進行中的戰鬥在地圖標示之上顯示持續的雙劍交擊，結束即停止；偏好減少動態效果時保留靜態標記。

檢查：`npm run test -- src/game/worldUiBehavior.test.ts src/game/batch200.test.tsx src/game/offlineEquivalence.test.ts` 15 項通過；`npm run build` 通過。整體舊測試包含與目前遊戲規則不符的歷史案例（例如早期地圖營地數與外交限制），未將其視為本次變更的驗收門檻。
