# 國戰 v0.4 — M0～M6 修訂與驗收

本文件記錄本輪實際交付。Master v0.3、原製作藍圖保持原文；本輪採用使用者最新指定的 AI 正規聚落、自選地塊建設、建築浮動視窗、兵力列與總督方針。

**結論：五項具體操作需求已實作；M0～M6 尚未全部通過驗收。** 可交付更新 Demo；不可把本文件視為完整 M6 簽核。

| 使用者需求 | v0.4 行為 |

| 點兵營開浮動視窗 | 點建築開原生對話框，顯示等級、作用、成本、工程時間，可升級或確認拆除。拆除後可換建。 |

舊 v0.3 戰役可自動遷移：保留人口、庫存、軍隊、城主與進行中的工程，轉為地塊模式。**舊世界不重新分配領土；新版 AI 村莊與遺址配置需新開戰役。** M0／M1 展示存檔仍保留於原資料庫，不混入不同情境。

## 自動驗證

43 項測試、10 個測試檔，全數通過。可在根目錄執行 `npm run check` 重現。

- 實際扣料與兵力守恆、掠奪返城入庫、無法超領駐軍、撤退不重複抵達。
- 地塊選址與排他、拆除重建、拆民居不刪人口、工作中的建築不可拆。
- 總督預算／庫存保留、關閉後停工、非法跨國批次命令原子拒絕。
- 居民建城／途中撤回、新手保護與核心最低警報。
- 三回合以上戰役、攻守增援、五分鐘改令、三小時補給中斷後延遲撤退。
- 攝政實際付費、實際調兵；首都失守後保留撤離人口／兵力／庫存，未憑空補兵。
- 存檔檢查碼與關聯驗證、進行中工程遷移、重複命令去重與外來戰役拒絕。
- 存檔故障注入：失敗不提交版本、目前快照損壞回退、全損壞時保留原資料並停止。**此測試使用交易儲存替身，驗證應用層回復；不冒充真實 IndexedDB 驗收。**
- 六文明 48h 結算及 24h／48h 追算，整段與切片結果一致。自動征服路線只用正式命令，沒有直接賦予資源、人口或軍隊。

本輪 headless 執行：48h 追算約 256～542 ms，存檔約 234～274 KiB。具體 seed、各文明數據見 `V4_HEADLESS_RESULTS.json`。這是 Node 模擬器量測，不能替代瀏覽器、GPU、Windows 硬體數據。純經營方針的六國測例以期限結算；並非六種文明都自動勝利。

PWA 預快取最低必要圖像與程式，約 9.66 MiB，低於藍圖 15 MB 建議值。實際載入速度尚待目標網路與硬體確認。

## 目前阻礙及下一次真正驗收

官方瀏覽器工具以網址安全政策拒絕本次預覽導覽。預覽服務本身正常；沒有改用其他瀏覽器、端口或網址繞過限制，因此沒有點擊或畫面實測紀錄。

依原藍圖，M6 仍需真實執行以下項目，不能用上述加速模擬冒充：

1. 原速 48h 戰役兩場，分別人工走完征服與霸權。
2. 關閉瀏覽器至少 8h，再開啟核對資源、軍隊、工程、警報及摘要。
3. 匯出後於乾淨瀏覽器資料匯入，檢查多分頁鎖、瀏覽器儲存故障、PWA 舊版更新。
4. 中階 Windows 的 Chromium／Firefox：1366×768、縮放 200%、鍵盤／窄螢幕、地圖 FPS、整體記憶體與寫入延遲。
5. 在使用者選定的 GitHub 儲存庫啟用既有 Pages 工作流程，驗證正式 URL、子路徑和離線啟動。

遊戲保持單機、本機存檔、可離線、無帳號／每日任務／付費加速。測試站發布不把遊戲改為服務型架構。
