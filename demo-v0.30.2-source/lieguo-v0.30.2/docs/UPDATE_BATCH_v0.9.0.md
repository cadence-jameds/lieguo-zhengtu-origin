# v0.9.0 — 清晰地圖與軍事科技圖鑑

使用者核准累積十項更新，並將「移除更改目標、保留撤退」併入第十項。

| # | 更新 |
|---|---|
| 1 | 首次開始每場新戰役進世界地圖，既有進度載入仍進城市。 |
| 2 | 地形從 32 格改為 16 格區塊，依縮放與裝置像素密度提高解析度；近景倍率最高 2，快取 96 MiB 上限，保留遠景 LOD 與視野剔除。 |
| 3 | 移除格線開關，格線固定在原生畫布獨立繪製；遠景使用較淡細線。 |
| 4 | 新建、升級及城防顯示細施工進度；等待中顯示等待，完工移除。新工作保存 started 起點，舊工作依原工期推算。 |
| 5 | 城市背景、建築、空地依場景座標同步縮放。名稱、等級與施工進度獨立疊放，不再壓縮建築高度。 |
| 6 | 招募採雙欄小卡（桌面依寬度增加欄數）與共用詳情浮窗，數量、每名／本批花費與時間在浮窗內操作。六種一般兵共用圖，六文明衛隊各一圖。 |
| 7 | 六項科技有專屬美術。手機與軍事共用 CatalogCard、CatalogDialog；桌面維持原時代科技樹並替換美術。 |
| 8 | 手機建國方略入口只保留進度數字，完整內容仍在浮窗，全部完成後不顯示。 |
| 9 | 手機建城兩步：先看地形、座標、居民與建材條件，再選護衛及看行軍時間。第二步才可送命令，返回保留兵力選擇。 |
| 10 | 行軍卡片可看任務、兩端、兵種數量、剩餘及預計抵達時間、居民及攜帶物資；可定位目的地。更改目標從 UI 移除；返程不提供撤退。 |

## 相容性與範圍

仍是單機，沒有新增付費、每日任務或服務型限制。v0.8.0 的資源、人口、兵種、時代、行軍速度與建城護送條件不變。不需要重新開局。舊存檔沒有工作 started 欄位仍可載入；舊改令繼續完成，沒有修改既定行軍。

美術由影像生成工具原創製作，並非擷取商業遊戲。詳細浮窗圖片保持 112–128px，卡片 86–100px；科技／軍事一致。

## 驗證

TypeScript 與正式打包檢查；施工開始、等待、存檔往返、舊工作進度、兵種／科技圖示對應、手機建城初始步驟、共用卡片及原有開局／建城／完整流程回歸。地形快取拖曳四個縮放比例測試。測試記錄見 validation/v0.9.0。

本輪沒有瀏覽器或手機實機驗收；快取測試是模擬畫布工作量，不代表實機 FPS。發布後優先確認：大地圖清晰度和拖曳、城市全景與放大比例、招募數量操作及建城兩步驟。
