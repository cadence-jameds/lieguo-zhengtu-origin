## 繪製耗時

同種子 902、同一山系視野，以 @napi-rs/canvas 執行正式景物函式；單位毫秒。下列為建立快取後 5 次重画範圍，並非完整瀏覽器影格時間或手機 FPS。

| 視野 | v0.29.9 | v0.30.0 |
|---|---:|---:|
| 近景 1200×800，z=1 | 15.2–20.2 | 1.9–9.1 |
| 遠景 1200×800，z=.3 | 66.6–90.8 | 2.5–3.3 |
| 地圖邊緣 800×600 | 39.9–48.0 | 3.3–4.4 |
| 手機畫布 390×650 | 4.3–6.5 | 2.5–3.1 |

冷快取仍需建立圖塊。正式頁面每幀分配軟預算，且使用完整低解析地形作底，不一次同步繪完整遠景。測試視野分 25 次補齊景物；單次 pump 中位數 4.75ms、最大 16.09ms，單一圖塊不可中斷，因此不是嚴格的 4ms 上限。完整低解析世界首次生成約 86ms，之後重用。進入遊戲時會預熱首都附近地表與景物。

## 實作要點與限制

- 山體遮罩由既有 atlas alpha > 140 的 64×64 採樣產生，忽略外圍淡影。樣本座標投影回格子，同一遮罩決定山體放置、水域避讓、建城與尋路。
- 舊存檔儲存 mountainRevision=1 與 mountainClearings；保留城市與活動目的地，取消有衝突的山體。非活動野外據點可搬到附近合法格，保留 ID 與內容；既有行軍保留時限並重算路徑。
- 地表快取上限 96 MiB，景物快取上限 48 MiB；不是整個分頁的總記憶體上限。
- labels 使用新的偏好鍵，第一次預設隱藏，玩家手動切換後記憶。
- 256×256 格線，地形外延 50 格，水域地理位置與既有成本不變。
- 未進行手機實機或瀏覽器互動驗證：本環境沒有 control-browser skill，依 Sites 指引未改用其他瀏覽器控制方式。
- 美術已依參考修正，仍須使用者以正式網站檢查；不將通過測試視為使用者已驗收。

可用 `node scripts/preview-map.cjs` 重做地圖輸出；需開發依賴及額外可用的 `@napi-rs/canvas`，它不是遊戲執行依賴。
