# v0.12.0 十二項更新與驗證

使用者已授權全部更新。後續維持累積 10 項再確認。

| 項次 | 功能 | 玩家驗證方式 |
|---|---|---|
| 1 | 倉庫與地庫分工 | 黑暗時代完成四種資源與民居前置後可蓋地庫；倉庫只增加容量，資源詳細資訊及地庫顯示保護量。 |
| 2 | 淺白 UI 選取／未讀提示 | 電腦與手機切換頁面，選取使用淡底細框圓角，未讀戰報呈內光閃動。 |
| 3 | 地圖工具配色與布局 | 三種主題切換，左下提示同步配色；電腦 XY 同列、加減並排；手機工具可展開。 |
| 4 | 帝國版圖 | 開啟帝國版圖後去除地形紋理、保留河流；只有帝國顯示色塊邊界名稱，軍團與獨立領主不顯示。關閉恢復原地圖。 |
| 5 | 治理方針與任務 | 原帝國方針改名治理方針；點任務查看統合河谷，即使四個初期任務完成仍有入口。 |
| 6 | 治理／運輸精簡 | 治理預設緊湊排列，勾選城市後出現批次操作；停工原因展開查看；運輸以清單為主，新增／編輯才展開表單。 |
| 7 | 後勤商隊 | 市場每級 5 支、每支 500，混裝 501 資源需 2 支。送達後至返城前仍占用支數；無招募、人口、維護費。 |
| 8 | 水域城市 | 水域不可建城或復國；舊水域城市讀入時移到鄰近陸地，保留城市 ID、建設、庫存與部隊，並留下記事。地形渲染使用實際逐格水域。 |

| 10 | 地圖復國選址 | 敗北→流亡復國→在大地圖選擇位置；紅格不可選、綠格合法，確認後才恢復世界。XY 為可選輔助。 |
| 11 | 城堡時代拓殖 | 玩家與 AI 須城堡時代才能派出新的拓殖隊；既有在途拓殖隊保留，復國不受此門檻限制。 |
| 12 | 城堡／文明衛隊 | 城堡時代開放城堡；本城有城堡才可在原募兵頁面生產文明衛隊。六文明城堡各有美術，不另設招募介面。 |

## 建築參數

地庫 Lv1–5：每類保護量 500／1000／1750／2500／3500。基本成本食60木100石120金0，各級 ceil(基本成本 × 1.7^(目標等級−1))。單級世界施工時間1／3／10／30／75分。全等級無時代限制，不增加倉储容量，只防掠奪、不防占領。

城堡 Lv1–5：基本成本食200木300石650金200；同樣成本倍率1.7。單級世界施工15／30／60／120／240分。每級提升文明衛隊訓練速度，使用既有訓練公式 1 + 等級×0.15；不額外增加城牆防禦。每城各一座地庫與城堡，使用原一般地塊。

市場每級提供2500總載重，改以500為單位向上取整占用。不同路線共用出發城市商隊。單次與固定路線運送至目的容量；補庫存模式另依目標量減去現有與在途物資。保留來源最低量、滿倉退回、城主改變停路線等規則。

## 相容性與驗證

保留原 schema 5，舊存檔缺少的地庫與城堡等級補0。不贈送新建築；既有文明衛隊與已付費訓練佇列保留，新募兵適用城堡門檻。旧商隊按實際載重向上取整為支數，返程後釋放。舊戰報不改寫歷史文字。

38 項相關自動測試通過，型別檢查及正式建置通過。測試涵蓋地庫逐級保護、玩家與AI城堡門檻、城堡時代建城、黑暗時代復國、商隊整支占用及往返釋放、路線編輯、舊建築欄位相容、水域搬移、帝國版圖歸屬、組織命名权限與儲存；並執行上一批戰局、離線、存檔相關回歸。未以實體手機做視覺驗證，三種主題及手機排版仍請依上表實際檢視。
