# B9 前戰役時間與快速設定

新戰役一般速度為1X、3X、6X、10X、25X；預設1X。離線推進為關閉、1、4、8、12個現實小時，預設12小時。離線一律按一般戰役速度補算。

遊戲中的⚙可用滑鼠或觸控拖曳。點擊後調整離散滑條，再按「套用並儲存」。只有保存完成才確認提交。戰役設定頁也能修改，並可關閉懸浮齒輪；位置和顯示開關只存在目前裝置。

開發者模式提供50X／100X前景加速、玩家資源補滿與保護罩。一般速度仍保留，關閉開發者模式後恢復。開發者倍率不參與離線補算。正式遊戲不再提供B5測試台入口，戰鬥引擎與測試保留。

本次更新強制建立新戰役。舊版進度不轉換、不補算；首頁說明原因並提供「匯出舊存檔備份」。舊資料仍保留在裝置中，新的戰役使用獨立資料區，不會混用舊事件、戰報、收據或回復點。舊備份僅供歷史封存，不能匯入新版繼續遊玩。
