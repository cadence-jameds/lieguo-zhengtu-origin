# v0.26.4 — 2026-09-23

1. 修正首頁可能長時間停在「正在讀取本機進度」：Web Locks 取得控制權改為最多等待 8 秒並使用 AbortSignal，避免鎖定請求本身尚未進入既有 20 秒 worker watchdog 時無限等待。
2. 若存檔鎖被其他分頁占用或取得控制權逾時，改為顯示明確原因與重新整理入口，不刪除、不覆寫現有 IndexedDB 存檔。
3. 讀取期間首頁不再顯示「尚無本機進度」，且「開始新遊戲」與「載入進度」皆暫停，等存檔狀態確認後再開放。
4. 保留 v0.26.3 世界地圖、資源據點比例、文字描邊、LOD 與存檔 schema；不改遊戲平衡。

此版為啟動／存檔安全修正。
