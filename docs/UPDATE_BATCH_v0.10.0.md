# v0.10.0 — 資源明細、勢力外交與城市命名

依使用者「請全部更新」實作全部 14 項。

1. 地圖說明改為小型問號浮窗，與手機任務進度並列。
2. 建築施工使用細金線；等待使用沙漏，百分比不佔地圖位置。
3. 科技與募兵詳情移除大圖，保留外層卡片美術，縮減重複時間與單位花費。
4. 更多僅保留首頁、設定、說明、任務；建國方略改為任務。
5. 建城資訊費用只列一次，不足標紅並顯示差額。
6. 建造與升級同步顯示不足差額。
7. 戰報恢復大圖橫幅，手機採滿寬較矮橫幅，概要與損失先顯示，戰鬥條件收合。
8. 人口基礎成長每世界小時 60 + 城市中心等級 × 15；中國 1.15 倍，住房、食物、穩定度門檻沿用。
9. 四種資源可點擊，逐座建築、加成、耗糧、淨收入、容量與保護量採引擎同源明細。
10. 桌面募兵直接編組與招募；手機保留小卡進詳情。淺色主題採米白表面、深灰文字與金色重點。
11. 偵察抵達即取得情報，不比較斥候數量，不損失偵察隊；攻守雙方收到戰報。被偵察不會完成玩家的偵察任務。
12. 倉庫 Lv.1 起固定保護現有各類庫存 20%，升級只增加容量；掠奪仍受載重限制。守方戰報顯示被掠奪量。
13. 建城時取名／骰子，城市中心或城市概況可反覆改名。AI 避開全圖既有名稱；舊系統新府名稱與 AI 重複城名自動整理。玩家新命名有標記，保留不改。座標独立於名稱顯示。
14. 帝國／軍團／領主分頁。外交命令僅帝國領袖或團長可執行，對象為另一勢力；成員遵守勢力外交。個人仍可偵察、進攻，無法締結外交策略。

## 相容性與驗證

保留存檔格式 5、原城市 ID 與行軍參照；城名自訂標记為可選欄位。舊戰報文字仍可閱讀，詳細條件收合。
情境驗證包含資源明細精確對帳、不可攔截偵察、雙方報告、倉庫保留兩成、成員外交約束、改名與存檔、人口成長、手機與桌面分流。
未進行實機手機或瀏覽器互動驗證。
