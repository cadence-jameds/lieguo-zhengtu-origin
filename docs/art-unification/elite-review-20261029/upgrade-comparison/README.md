## 來源與對齊方式

一般兵種直接執行專案現有 `unitArt`／`armyAtlasBounds` 取得來源，不從舊精銳反推。正式名稱和本輪審圖稱呼如下；「一般連弩兵」不是 `crossbowman` 通用弩兵。

候選直接使用既有 [A／B／C 展示 WebP](../candidates/)；它們與 [outputs.json](../outputs.json) 的 SHA256 一致。未重新轉製、覆寫或挑換候選。既有 [原始 PNG](../raw/) 及生成歷史完整保留；中國 C 使用現有 `china-C-imperial.webp` 對應的修正版，不用已退件的 C 初稿。

所有輸入先保留整張來源（一般兵僅作正式遊戲已定義的圖集裁切），再以相同規則做**等比縮小與平移**：以金屬盔體頂部至最低可見鞋底為 360px，統一置於 512×512 畫布，盔頂 y100、腳線 y460。紅纓、盔角、刀尖不拿來當身高；不同甲冑寬度、姿勢與武器長度原樣保留，沒有非等比拉伸或按肩寬個別填滿畫布。十個輸入都只縮小，沒有放大任何候選，完整來源邊界均留在畫布內。

盔頂／鞋底是人工語義標點，約 ±4 個來源像素誤差；不是自動人體骨架量測，也不代表調整了素材本身的人體比例。來源內既有暗色背景照留，外層畫布顏色一致，不去背、不塗改。金色短線在圖外標示共同腳線，不蓋住角色。128／64px 一律由同一套 512px 比較卡等比縮小，角色盔頂至鞋底分別為 90／45px；它們用於控制尺度的升階審圖，不冒充遊戲 UI 截圖。

完整路徑、SHA256、正式 selector 結果、人工標點、縮放／平移數值、每個圖塊的座標均在 [manifest.json](manifest.json)。腳線與盔頂的對齊不消除美術本身的肩寬、體態與姿勢差異。

## 重現與檢查

```sh
python3 docs/art-unification/elite-review-20261029/upgrade-comparison/build.py
python3 scripts/check-art-boards.py
python3 scripts/check-city-visuals.py
python3 scripts/check-player-feedback.py
```

`build.py` 只寫入本審圖目錄。它透過 `query-runtime.cjs` 執行現有 TypeScript selector，檢查一般兵不是精銳註冊圖、候選 SHA 與既有記錄一致、所有變換只縮小且不裁掉來源邊界，並確認輸出圖中的 128／64px 美術區域與同尺度卡面像素一致。輸出為無損 PNG；沒有為了比較板修改 Runtime、舊圖板、舊生成紀錄或驗收程式。整體 GitHub CI 請以本輪提交實際執行結果為準。
