## 生成結果自檢

胸腹、圓肩、護頸、護臂、裙甲與脛部保留向下重疊的圓形魚鱗，沒有沿用 D 的矩形札片；紅纓、深鐵與暗紅衣料、木製上彈匣連弩及人物身分延續 B。前腿向畫面右方跨出，後膝落地，兩腳可見；披風向左展開，整體輪廓低而寬。原 B 的站姿圖完整保留，沒有覆寫任何舊候選。

全圖與手部近看可見兩條連接的手臂、後手持弩身控制區、前手由下方托住木架，未見第三手／第三臂、重複連弩或弩穿頭。弩弓、弦、彈匣、紅纓與兩腳均在畫布內。部分指節遮擋，不逐指保證；弩機沿用原 B 的外觀，含環狀控制件，沒有宣稱完成機構工程或歷史考據驗收。這是原視覺自評；玩家審圖現已定案，獨立肢體複審仍待驗，未宣稱獨立 ART-GATE PASS。

128px 尚能看見圓肩魚鱗與裙甲覆蓋；64px 的個別鱗片無法逐片辨讀，但後膝落地、前腳跨出與向後披風仍形成不同於一般兵及原 B 站姿的低位輪廓。沒有把材質大圖可見誤記為 64px 細節通過。

一般兵與現行精銳直接執行目前 `unitArt`／`armyAtlasBounds` 取得，四欄均完整等比縮小到最大邊 480px、置於 512×512 畫布、鞋底對齊 y450，沒有放大候選、裁掉來源、非等比拉伸或將跪姿拉成站姿高度。生成構圖與人體比例差別仍可見，未宣稱精確骨架同尺度；鞋底人工標點約 ±4 來源像素。128／64px 均由同一比較卡縮小，手機直排的美術區域是實際 128px。
