# PR #44 帝王城市比例檢查與修正

**判定：確認有複合的佔位／構圖問題，不是單純拼接錯覺。** 六文明帝王圖其實較窄，不是整張任意放大；但高度更高、統一 y480 腳點與舊圖不一致，且世界地圖混用了「整座城市」與「文明中心」兩種用途。本輪只修正這些美術層，原生成 PNG、前三時代圖、科技圖、玩法及 v95 均未更動。

## 各層原因

| 層面 | 判定 | 處理 |
|---|---|---|
| 原始生成構圖 | 帝王主要建築更突出、高度／地面輪廓與舊圖不同。不是靠留白即可完全變成同一構圖。 | 保留進階宮殿、教堂、城堡與帳殿，不重繪建築、不增刪城市內容；只作整體等比校準。 |
| 圖集裁切 | 原流程取最大 alpha 連通物件、保留邊緣，再塞入 460×440 安全框，沒有把方格當作實際地面尺寸。切格沒有選錯文明。 | 沿用原連通物件提取，不重新切壞城市，不更動原 PNG。 |
| thumbnail / resize | 六文明五欄原本都是 512×512 全畫布，最終相同 202／512 倍率；沒有只把新帝王放大。 | 保留同倍率。加尺寸斷言、[逐格版面紀錄](../boards/city-board-layout.json)與城堡腳點參考線，避免用逐格可見外框填滿來掩蓋比例。 |
| canvas paste | 原通用 Sprite 流程一律貼到底部 y480。前三時代的每文明腳點本來就不相同，底排三文明新帝王特別下移。 | 城市獨立校準：對齊同文明城堡腳點與水平外框中心，等比例縮小超高者，不拉伸寬高。 |

## 六文明精確外框比較

測量以 alpha >96 的可見物件為準，右／底為 exclusive 邊界；像素精確的外框不包含低透明陰影。下表對照同文明城堡，**並非要求所有文明變成同一座城市或同一腳點**。

|---|---|---|---|---|
|中國|498×351／463|454×361／478|454×361／463|1.0000|
|拜占庭|489×367／461|454×391／478|452×389／461|0.99494|

|蒙古|498×329／407|455×376／477|422×349／407|0.92750|

修正前帝王有效寬度比城堡小約 7～11%，高度卻高 2.8%、6.5%、7.0%、3.7%、4.4%、14.3%；新圖下移分別 15、17、8、75、70、70px。不列顛、日本、蒙古的腳點偏差最明顯；蒙古另有最大高度偏差。黑暗／封建／城堡自身也有既有腳點差異，尤其底排黑暗圖較早收底，詳見全表，沒有把歷史圖偷偷重新縮放。

全城高度上限採「同文明城堡 ×1.06」，只對超出的帝王圖微縮；單一 affine transform 同時縮寬縮高，再平移，沒有水平／垂直各自拉伸或改變建築結構。帝王城市仍保留較高的主建築與較華麗的構圖；例如中國主殿的人工標點高度仍比城堡高約 48%，這是多層宮殿的構圖差異，沒有把它偽裝成相同建築。修正後全城高度差為約 2.8～6.1%，腳點誤差 0px，外框水平中心偏差 <=1px。帝王寬度仍保留自身自然輪廓，沒有為了追平舊圖寬度而拉胖城市。

- [每文明每時代完整尺寸表](measurements.md)：黑暗、封建、城堡、舊帝王、新帝王，另列修正前帝王，共 36 個比較列；有效 W/H、主建築高度、地面佔位、左右留白、底部腳點、外框中心偏移。
- [可讀 JSON](measurements.json)：亦含 alpha 佔位像素、alpha 重心與所有座標。
- 主建築與地面屬語義：主建築屋頂／基座是人工標點、誤差約 ±12px；地面受房屋遮擋，使用人工後緣與可見城市外框的投影包絡估測、誤差約 ±16px。這些**不是精確土地面積**，不把自動 alpha 統計冒稱語義分割。每格標點圖可直接審核。
- [實際校準參數](calibration.json)記錄來源外框、目標外框、倍率與平移；[候選比對](calibration-candidates.webp)並排原城堡、原帝王、只對腳點、腳點＋高度上限，選用最後一種。
- 原素材保存在生成 PNG 及 Git 歷史；[修正前正式圖集](before/cities-imperial.webp)與[原對照板](before/board.webp)另留本輪證據。
