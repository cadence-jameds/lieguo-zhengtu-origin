# 列國征途 v0.30.24｜Demo 地圖、出征與偵察介面修正

日期：2026-10-08（Asia/Taipei）
基線：v0.30.23，B5 完成版本；規則 authority 仍為 v86 > v85 > v84 > source。未開始 B6。

## 使用者參考

依使用者提供的 v0.30.2 三張截圖及保留的 Demo `Mission.tsx`，移植顯示與操作結構。沒有引用 legacy combat、march、intelligence 或 persistence 作正式規則。

## 修正結果

- 地塊資訊恢復 Demo 的名稱、座標、玩家／文明／關係、已知駐軍／城防／人口、歷史資源情報與獨立行動按鈕。
- 城市可直接選擇「派遣斥候」「掠奪物資」「佔領據點」；己方或既有同帝國授權目標顯示增援。
- 地圖直接開啟任務對話框；不跳到軍隊頁、不再要求重填目標座標。返回恢復地塊資訊，保留原 Canvas、視角及倍率。
- 出征恢復來源城市 → 目標／領主 → 單程時間、編入部隊、逐列可用數量、返回／下達命令。偵察預設至多 2 名斥候，保留 Formal 情報模式選項。
- 時間預覽採 Formal 合法路徑及實際選取兵種／科技的行軍速度，送出的仍是原 `army.dispatch` 命令。
- 敵方守軍、城防與資源不讀取即時隱藏值；只顯示已回城、已提交、屬於玩家的歷史偵察戰報。各情報類型保留各自觀測時間。
- 情報查詢由既有單一 Worker 讀取既有 BattleReports IndexedDB；沒有新 DB、schema、authority row 或戰役狀態。查詢依 campaign、report cursor 與世界時間限制，失敗不暫停戰役。

## 邊界

- 軍團／完整外交仍未開放，不虛構 Demo 組織名或外交關係。
- 既有 B5 authority 下，野外據點只接受掠奪；偵察按鈕保留停用並說明，未將 Demo 野外偵察規則移入 Formal。
- 原子攻城、結算 receipt、退款、432-slot wild lifecycle、世界速度及戰術封頂等正式規則保留。
- 圖像、美術、地形生成、地圖畫法均未改動；CSS 僅針對資訊與任務選單。

## 驗證

完整 Core regression：46 files／445 tests PASS，0 failed、0 pending。詳見同目錄 core-regression.json / .txt。自動化包含 393px 與 1440px Canvas／DOM 操作、原地圖返回與派遣、兵力與任務命令、合法時間預覽、歷史情報跨 50 則分頁／重新連線／游標切割、Worker 查詢和失敗處理。
