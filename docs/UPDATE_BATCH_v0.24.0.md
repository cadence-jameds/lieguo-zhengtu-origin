# 河谷戰役 v0.24.0 — 本輪三項更新

1. 世界地圖恢復文明單字（中／拜／法／不／日／蒙），保留敵我色框、描邊、碰撞避讓與顯示標示開關。文明選擇與側欄的專用徽記保留。
2. 地形區域化：以連續地域取代 7×7 隨機方塊；地表貼圖使用世界座標跨格取樣，森林、丘陵與平原柔和混合。河道判定公式完全保留。格線、帝國版圖淡地形、資源點隱藏及縮放快取保留。
3. 世界種子碼：新開局預設隨機，可輸入或按骰子重抽；僅接受 0～4294967295 整數，空白與錯誤輸入會阻止開局。相同版本、種子與文明可重現初始世界，戰役設定頁保留種子供查閱。

## 舊存檔與影響

- 不重設城市位置、人口、資源地配置、建設進度或已出發的行軍路線／抵達時間。
- 保留既有河道與水域建城限制。陸地地域更新後，新行軍按照新地形計算，成本倍率本身未改。
- 不需要重開即可看見文字與新地形；種子設定只影響新戰役。
