# 列國征途 v0.27.21 更新清單

基底：v0.27.20。沿用現有戰役與收藏存檔結構，更新後保留進度。

1. 城郊資源格移除上版新增的橢圓亮框；四級以上建築的懸停發光及鍵盤聚焦提示仍保留。
2. 電腦版世界地圖右側加入「⋯」收納，預設顯示放大、縮小、收納鍵；展開後每項功能仍是單獨按鈕。
3. 可建城的地塊資訊標題，在座標旁以星星直接收藏或取消收藏；滿五組時停用新增，移除下方重複的收藏按鈕。
4. 我的最愛清單改為不遮暗地圖的可拖動小浮窗，與手機、電腦共用；欄位先顯示「糧/木/石/金」，每組以「8/5/3/2 (座標)」顯示，可點選定位或刪除，最多五組。
5. 手機和電腦世界地圖右側按鈕統一縮成窄版單列，依原順序顯示；長標籤按語意換行，例如「帝國／版圖」、「隱藏／標示」，最下方為「★ 最愛」與收藏數「3/5」。
6. XY 定位改為與我的最愛相同的可拖動小浮窗，提供 X、Y、前往及關閉；輸入維持 0～255 的整數檢核，定位後浮窗關閉。

本次變更只涉及介面呈現與地圖定位，沒有改動存檔格式或戰鬥規則。

驗證：`npm run build` 含 TypeScript 型別檢查通過；既有收藏上限、匯入及關聯規則的 4 項測試通過。瀏覽器的本機預覽連線受執行環境阻擋，未取得手機與電腦實際畫面截圖。
