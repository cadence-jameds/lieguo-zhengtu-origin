# 時代、科技樹與城市呈現修訂

- 城市中心維持中央，15 個地塊採人工錯落座標，取消環狀配置。地塊 ID、用途與既有工程保留。
- 點城市中心可晉升封建／城堡時代；原本人口、學院、中心、兵營、資源與研究佇列條件保留。
- 研究頁只列科技，依三個時代分欄。六項科技顯示建築圖示、所需等級、前置科技、成本、時間、未解鎖／研究中／完成狀態。
- 黑暗：輪作耕作（農田1，食物+10%）、木工技術（伐木場1，木材+10%）。
- 封建：基礎鍛造（兵營1，戰力+5%）；補給道路（市場1＋木工技術，行軍時間−15%）。
- 城堡：灌溉水利（農田3＋輪作耕作，再加15%食物產量）；鍛鋼（兵營2＋基礎鍛造，戰力+12%）。輪作與灌溉為基礎產量的加總加成，鍛造與鍛鋼為獨立乘數。
- 科技條件由遊戲引擎強制檢查；AI使用同樣條件。效果為全國採用，建築條件檢查目前研究出資城市。
- 新增科技存檔可讀寫；舊存檔已完成科技保留，不追回舊版效果。
- 建築及城市圖示隨所屬文明的時代切換。新原創黑暗／封建圖集各含20個建築，5欄4列；城堡沿用既有圖集。圖集透明度保留，SVG與地圖Canvas共用來源裁切規則。
- 頂列依資源、時代、兵力呈現；手機保留獨立版面。

美術製作使用內建 imagegen。新增檔案：public/art/buildings-dark.png、public/art/buildings-feudal.png，各1536×1024 RGBA。
