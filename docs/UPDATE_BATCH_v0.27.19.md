# 列國征途 v0.27.19 更新清單

基底：v0.27.18。於 2026-09-27 確認發佈。

1. 戰報「戰鬥詳情」改為有邊框、展開／收合字樣與箭頭的觸控區。
2. 戰報中的攻擊者與守方姓名使用不同顏色，深色及淺色介面皆可分辨。
3. 世界地圖選中的城市沿用底下的菱形方框持續閃動，移除額外橢圓亮框。
4. 世界地圖選中的野外資源據點也沿用菱形方框持續閃動。
5. 在地圖直接點選據點時維持目前視角，不移動鏡頭。
6. 從城市下拉選單切換時將城市置中；再次選同一座也能重新置中。
7. 城牆施工進度條不再繼承城門名稱的黑色框。
8. 城牆排隊中的沙漏不再繼承城門名稱的黑色框。
9. 比對六個文明與三個時代的施工圖尺寸後，校正城堡時代文明市政廳及部分時代共用建築的尺寸；倉庫與其他已對齊的素材保留原比例。
10. 有城牆的城郊城市放大至更靠近牆身，無牆城市維持原尺寸；逐一核對六文明與三時代的城市與城牆素材。

驗證：針對戰報、城郊、各建築施工圖及城牆場景的 25 項檢查已通過；正式建置通過。
