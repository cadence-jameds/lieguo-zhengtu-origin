## 2. 工作 A：v95 §19｜建築前置／資源加工／科技／修道院

**建築與前置**
- 城牆：黑暗時代、城市中心 Lv1 可建；兵營仍需城市中心 Lv2。
- 鐵匠鋪仍需兵營 Lv3，學院仍需鐵匠鋪 Lv3；馬廄仍需兵營 Lv5；使館仍需市政廳 Lv1。
- 城堡：城堡時代＋**市政廳 Lv5 + 城市中心 Lv8**（不再強制學院 Lv5）。
- 攻城工坊：城堡時代＋**學院 Lv8 + 城市中心 Lv8**（不再用鐵匠鋪5＋兵營5）。
- 保留城堡／攻城工坊功能、成本、工期、科技、文明衛隊、攻城兵、輜重車、拓殖隊及工匠團原有權限。工匠團免費城堡 Lv1 仍需遵守新建築前置與時代；不能直接繞過驗證。

**四類加工建築：磨坊／鋸木場／石匠工坊／鑄幣所**：最高 Lv8、每級 +4%、每城每種類最多一座，依以下統一資格實作：
- Lv1：任一對應資源田等級 ≥3。
- Lv2：兩個**不同 slot** 的對應資源田，各 ≥4。
- Lv3：兩個**不同 slot** 的對應資源田，各 ≥5。
- Lv4：**全部實際存在的同類田**平均等級 ≥5。
- Lv5：同類田平均 ≥8。
- Lv6：同類田平均 ≥10。
- Lv7：同類田平均 ≥11。
- Lv8：同類田平均 ≥12。
只一格同類田的城市，加工建築只能 Lv1；15/1/1/1 專精城不提供特例；不能拿單一高級田代替兩格。成本／工期／同類田計數仍依 v95，City 資源田 Lv11～15 資格不變。Formal command validation、UI 缺額顯示、AI 都必須同權。

**資源科技**：農業、林業、採石、採礦 I +3%、II 再 +5%、III 再 +10%，完整 +18%；不變更研發資格、等級、花費、時間、勢力所有權。最終資源田產量 =
Σ 同類田基礎產量 × (1 + 加工建築 Lv × 0.04) × (1 + 各已完成科技階段的 0.03/0.05/0.10 總和)。
滿加工 Lv8 + 全科技 = 1.32 × 1.18 = 1.5576。不能照舊用科技完成數 ×0.03，也不能誤乘加成到非資源田收入。

**修道院**：原城堡時代＋市政廳 Lv5、每城一座、最高 Lv15、每級人口成長 +2%、Lv15 +30%、原成本／施工時間／不增加住房上限皆不變。新增獨立信仰奉獻：
- P = 本城**實際**人口；L = 已完工的修道院 Lv（0..15）。
- 每世界小時金 = min(max(P,0),30000) × L × (L+10) / 4500。
- P=30000、L=15：**2500 金/h**；無修道院 =0；超過30000人口奉獻仍封頂。
- 新建／征服／接收城市「統治初定」期間，**信仰奉獻與原有資源田最終產量一樣 ×0.40**；完成後各恢復正常。其他收入不降，不降低人口自然成長。
- 不受鑄幣所與採礦科技加成；不消耗平民、糧食或庫存；收入入本城黃金庫存，受正式每資源倉儲容量、reservedIncoming、overflow 與小數餘額限制。
- 注意人口成長是連續的。不可只拿結算結束時人口 × 全區間計算奉獻；使用正確時間積分／等價確定性分段，處理人口成長、徵兵、人口上限、修道院施工完成／拆除、統治初定中途結束、玩家命令和事件時間點。1X／10X／50X、刷新、讀檔、離線快轉、重放必須等價且不重複入帳。依既有懶結算及正式 ledger 設計進行最小必要擴充。
- UI 應明確展示人口增長與黃金奉獻是兩個不同功能；目前人口可得奉獻金／h、統治初定折扣、倉庫溢出皆顯示真實世界值。
