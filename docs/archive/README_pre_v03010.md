## 開始試玩

第一次建議選「快速試玩」：一個世界小時等於 30 秒，完整 48 小時戰役約 24 分鐘。也可選 12×（四小時）或原速（48 小時）。離開頁面後世界仍持續追算。

1. 進城市點選建築升級，或點空地選擇建物；點兵營可升級、拆除，軍隊頁招募槍兵。
2. 在地圖點城市、盜賊或資源據點開啟浮窗。領主與文明公開；派斥候取得駐軍情報，再決定是否出征。
3. 點空白陸地建立第二城，或佔領 AI 城市。帝國方針可批次委任總督，自動依預算建設。增援與市場運輸使用各城實際兵力、庫存。
4. 建學院、發展人口，前進封建與城堡時代。
5. 透過戰爭與要求臣服統合其他領主，或建立三十座有效聚落的霸權。

「?」提供遊玩說明。設定中可匯出存檔、回復備份與開新戰役。

## 本機執行

需要 Node.js 22.13 以上，在專案根目錄執行：

    npm ci
    npm run dev

依終端顯示的網址開啟，不能雙擊 index.html。專案已包含 src/hooks/useWorldEngine.ts 與完整別名設定；目前遊戲入口為 src/game/GameApp.tsx。

    npm run check

執行型別檢查、全部測試與正式建置，輸出為 dist/。戰役／城市／存檔故障測試位於 src/game/，六文明追算 runner 位於 src/devtools/demo48h.test.ts，M1 原有測試保留。

## GitHub Pages

保留 .github/workflows/deploy-pages.yml，可將整個專案根目錄推送到自己的 GitHub 儲存庫，使用 GitHub Actions 作為 Pages 來源。工作流程由 main 分支安裝、驗證、建置與發布。一般專案 Pages 使用儲存庫子路徑；username.github.io 類根站使用根路徑。

個人測試站與 GitHub Pages 是不同瀏覽器儲存來源；搬移戰役時請先匯出再匯入。網站沒有遊戲帳號、後端遊戲伺服器或雲端存檔。

## 存檔與範圍

本機 IndexedDB 自動存檔，保留五份回復點。換裝置、使用無痕模式或清除瀏覽器網站資料前請先匯出。Demo 使用 Schema 5，支援原 Demo v3／v4 遷移。既有領土與行軍保留；v0.8.0 可直接載入 v0.7.0／v0.6.0 進度，M0／M1 舊資料仍保留在原處。

目前最高城堡時代。最新更新與驗證範圍見 [v0.8.0 批次紀錄](docs/UPDATE_BATCH_v0.8.0.md)；M0～M6 的初期追蹤保留在 docs/M0_M6_ACCEPTANCE_v0.4.md，屬歷史紀錄。美術來源見 ART_ASSETS.md。實機手機與長時間遊玩仍需持續收集回饋。
