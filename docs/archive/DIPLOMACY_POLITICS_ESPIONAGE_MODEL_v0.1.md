## 1. 文件定位

本文件正式定義：

1. 文明如何接觸、談判、簽約、履行、違約、宣戰、停火、投降與附庸。
2. 信任、威脅、利益、依賴、恩怨與聲譽如何分開記錄，而不是壓成單一好感度。
3. 外交訊息、使節、情報與條約如何受距離、通信和世界時間限制。
4. 國內派系、政府合法性、戰爭支持、革命與分裂如何由真實世界狀況形成。
5. 間諜網如何建立、執行、暴露、被反情報追查及傳回結果。
6. 科技竊取、煽動、破壞與欺敵如何影響世界，又不跳過上游硬條件。
7. 流亡政府、占領抵抗、盟助與復國如何取得合法入口而不免費生成資產。
8. 反霸權聯盟如何同時作用於玩家與 AI，且不新增外交勝利。

本文件不替 AI 決定「想做什麼」，而是把 AI Civilization Model 提出的意圖轉換成合法外交、政治或情報行動。

## 2. 外交首先要形成選擇與故事

### 2.1 核心體驗

玩家應能：

- 從地理、貿易、歷史與公開行為理解鄰國為何合作或敵對。
- 用有限讓步換取時間、通行、資源、情報或共同防禦。
- 透過可靠履約累積信用，也能在危急時違約並承擔後果。
- 以附庸、自治、停戰或投降結束戰爭，而不是每國都打到最後一城。
- 藉由情報了解可能意圖，但永遠分得清事實、估計與敵方說法。
- 支持流亡政府或抵抗力量，改變世界歷史而不憑空召喚軍隊。

### 2.2 不做外交解題器

- 關係達 80 不代表必然同意所有要求。
- 條約不提供永久免戰或不可違反的魔法牆。
- 一份禮物不會洗掉大屠殺、背叛或長期占領。
- 同盟仍有自己的補給、軍力、國內政治與戰線。
- 間諜成功不直接顯示全國真實資料。
- 玩家不能靠重複送出、取消提案刷取好感或重抽結果。

### 2.3 單機外交的優勢

因為對手是 AI，系統可以：

- 保存數十日的承諾、恩怨與談判理由。
- 清楚解釋接受、拒絕或反提案的主要原因。
- 讓世界在玩家離線時照常談判、結盟與變動。
- 避免真人外交中的騷擾、欺騙性付款或必須同步在線。

但 AI 不可讀取玩家未送出的草稿、在線狀態或真實隱藏數據。

## 3. 政治與外交實體

### 3.1 政治實體

| 實體 | 可擁有的能力 |
|---|---|
| 主權文明 | 領土、軍隊、外交、條約、宣戰與勝利資格 |
| 城邦／部族 | 有限領土與外交，可成長、附庸或合併 |
| 附庸／保護國 | 保留部分政府，受宗主條款限制 |
| 叛亂政權 | 有真實人口、組織、資產、控制區與主張 |
| 殘存政權 | 首都失守但仍有城市或成建制殘軍 |
| 流亡政府 | 無受控城市，但政府與資產受庇護 |
| 占領抵抗 | 依忠誠人口、地下網路與隱藏資產運作 |
| 休眠主張 | 暫無可用資產，但文明身分及歷史主張保留 |
| 聯盟／陣營 | 條約組織，不是憑空擁有資產的超國家 |

### 3.2 個人與組織

- 統治者與繼承者。
- 政府內閣或議會。
- 行省總督。
- 將領與軍事集團。
- 商人、地主、學者、宗教或文化領袖。
- 外交使節與情報機構。
- 地下組織、抵抗網與流亡委員會。

只有會改變決策、忠誠、外交或事件的人物才建立具名資料；不逐一模擬全部人口。

### 3.3 外交承認與實際控制分離

一個政權可以：

- 有土地但不被多數國家承認。
- 無土地但仍被承認為合法政府。
- 擁有法理主張但沒有行政或軍事控制。
- 控制城市但被視為占領者。

World Map v0.1 的法理所有權、行政控制、軍事控制及通行權保持分離。

## 4. 關係不是單一好感度

### 4.1 六個主要維度

| 維度 | 範圍 | 意義 |
|---|---:|---|
| 信任 Trust | −100～+100 | 是否相信對方會履約及如實行動 |
| 威脅 Threat | 0～100 | 對方有能力且可能傷害本國的程度 |
| 恩怨 Grievance | 0～100 | 尚未解決的損害、羞辱、領土與傷亡 |
| 尊重 Respect | 0～100 | 對能力、穩定、承諾及威懾的評價 |
| 利益一致 Alignment | −100～+100 | 目前核心利益是否相容 |
| 依賴 Dependence | 0～100 | 貿易、資源、安全、技術或交通依賴 |

「害怕但依賴」與「信任但利益衝突」會產生不同外交，不應得到相同態度分數。

### 4.2 關係姿態

姿態由多維狀態、條約和戰爭共同推導：

| 姿態 | 一般含義 |
|---|---|
| 未知 | 尚未接觸 |
| 接觸 | 知道存在，缺乏正式管道 |
| 中立 | 無主要合作或敵對承諾 |
| 合作 | 有貿易、通行、交流或共同利益 |
| 友好 | 高信任且有持續合作 |
| 盟友 | 有明確共同防禦或作戰條款 |
| 競爭 | 有利益衝突但未進入敵對 |
| 敵對 | 威脅、制裁、最後通牒或準戰爭 |
| 交戰 | 已存在合法戰爭狀態 |
| 宗主／附庸 | 依具體附庸條款運作 |

姿態是介面摘要，不取代六維資料。

### 4.3 雙向且不對稱

A 信任 B，不代表 B 信任 A。每個方向分別保存關係、已知情報、條約理解與國內輿論。

### 4.4 記憶

事件記憶包含：

~~~text
事件類型
發生時間
直接損益
傷亡與領土
是否違約
是否公開
證據可信度
責任歸屬
衰減方式
尚未履行的補償
~~~

小型摩擦會逐步衰減；割地、背叛、大規模平民傷害與救國援助可保存整局。

## 5. 接觸、通信與外交時間

### 5.1 接觸層級

| 層級 | 條件 | 可用行動 |
|---|---|---|
| 傳聞 | 間接知道存在 | 無正式提案 |
| 已發現 | 見到領土、軍隊或商隊 | 簡單信號、尋找管道 |
| 非正式接觸 | 商人、邊官或使者接觸 | 地方交易、交換基本消息 |
| 正式關係 | 建立使節或外交管道 | 條約、通行、和平與抗議 |
| 常設使館 | 有人員、通信與接待 | 更快談判、較佳理解與情報 |
| 即時通信 | 合法電報或無線電接通 | 快速提案；批准與執行仍需時間 |

### 5.2 外交訊息必須送達

~~~text
外交回合時間
= 發送處理
+ 第一哩
+ 實際通信或使節路程
+ 接收與翻譯
+ 對方決策
+ 回覆傳回
~~~

早期跨區談判可能需要數小時至數日；電報和無線電可縮短傳遞，不能自動消除政府審議、國內批准與實體交付。

### 5.3 通信錨點

| 方式 | 上游典型時間 |
|---|---:|
| 當地視距／信號 | 1～5 分 |
| 傳令員 | 10～30 分 |
| 區域驛騎 | 30 分～2 小時 |
| 跨行省郵驛 | 2～8 小時 |
| 電報 | 5～20 分 |
| 無線電 | 1～5 分 |

實際時間使用 World Map 的距離、路線、攔截、設備與最後一哩。

### 5.4 提案版本

每次提案保存：

- 完整條款版本。
- 發送、收到、回覆與到期世界時間。
- 哪一方已批准。
- 是否因戰爭、政變或條件失效而需重新確認。

接受舊版本不會默認接受後續修改。

## 6. 條約由條款組成

### 6.1 條約基本欄位

~~~text
締約方
生效與到期
適用地區
公開或秘密
各方義務
禁止行為
履行時間
退出與續約
違約認定
補償與保證
批准狀態
~~~

### 6.2 條款類型

| 類別 | 例子 |
|---|---|
| 和平 | 停火、停戰期、互不侵犯、邊界 |
| 經濟 | 貿易、關稅、資源交付、貸款、賠償 |
| 通行 | 商隊、軍隊、港口、領空、海峽與補給 |
| 軍事 | 保證、共同防禦、共同目標、兵力承諾 |
| 情報 | 分享範圍、延遲、來源保護、反間諜合作 |
| 科技 | 授權、樣本、專家、共同研究與使用限制 |
| 政治 | 承認、附庸、自治、宗主權與繼承 |
| 領土 | 割讓、歸還、非軍事區、租借與控制 |
| 執行 | 抵押、觀察員、階段交付、違約補償 |

### 6.3 常用條約模板

介面可提供：

- 貿易協定。
- 互不侵犯。
- 通行協定。
- 防禦同盟。
- 共同戰爭協定。
- 停火與和平。
- 保護國／附庸協定。
- 技術授權。
- 流亡政府庇護與承認。

模板只是預填條款，所有效果仍由實際條款決定。

### 6.4 條約不自動傳送資產

「每 24 小時交付 10,000 食物」需要：

- 可用庫存。
- 付款或援助預算。
- 真實商隊、港口或鐵路。
- 合法通行和安全。
- 裝卸與抵達。

未能交付會形成延遲、不可抗力或違約判定，不由簽約瞬間完成。

## 7. 談判

### 7.1 提案結構

每份提案包含：

~~~text
我方要求
我方提供
生效時間
期限
履行方式
最低接受組合
可談範圍
秘密與公開程度
~~~

### 7.2 接受評估

AI Civilization Model 提供：

~~~text
直接利益
+ 戰略一致
+ 信任與履約預期
+ 依賴與替代成本
+ 國內派系支持
+ 威懾與安全
- 資源、領土與機會成本
- 長期威脅
- 恩怨與聲譽風險
- 其他條約衝突
~~~

Diplomacy Model 檢查條款是否合法且可執行。

### 7.3 回應

- 接受。
- 拒絕並提供主要原因。
- 提出一份明確反提案。
- 要求補充情報或保證。
- 延後到指定決策時間。
- 因通信、政變或權限失效無法回覆。

AI 不用無限次逐項加價拖延玩家。

### 7.4 重大條約批准

割地、附庸、宣戰、永久通行、世界工程承諾及政體改變可需要：

- 統治者。
- 政府或議會。
- 主要派系。
- 受影響行省。

批准時間及支持度由國內政治決定。緊急政府可以縮短，但增加合法性與派系代價。

## 8. 履約、信用與違約

### 8.1 三種履約結果

| 結果 | 定義 |
|---|---|
| 履行 | 在條件及時間內完成 |
| 延遲／不可抗力 | 有努力和合理原因，可能需補交 |
| 違約 | 有能力或承諾卻拒絕、暗中破壞或故意規避 |

### 8.2 信用

信任與國際聲譽依：

- 是否按期交付。
- 是否提供真實可驗證資訊。
- 是否在盟友受攻時履行條款。
- 是否提前協商無法完成的義務。
- 是否重複利用模糊條文。
- 是否善待投降者、俘虜與平民。

聲譽是其他文明依公開資料形成的估計，不是宇宙全知分數。

### 8.3 違約後果

- 信任下降。
- 恩怨與威脅提高。
- 產生宣戰或制裁理由。
- 盟友重新評估。
- 國內派系支持改變。
- 未來提案要求保證、抵押或更高價格。

後果依證據與影響，不是所有小延遲一律等同背叛。

### 8.4 退出

條約可包含通知期。正常退出在通知期後生效；緊急違約可以立即行動，但承擔較高後果。退出通知也須通信送達。

## 9. 通行權、國境與中立

### 9.1 權利分開

條約可分別允許：

- 商隊。
- 平民與難民。
- 外交使節。
- 軍隊。
- 海軍使用港口。
- 軍用補給。
- 飛越領空。
- 追擊特定敵軍。

一項允許不自動包含其他項目。

### 9.2 跨境檢查

部隊下令前和進入邊界時都檢查：

- 當前條約版本。
- 單位與任務類型。
- 地區和時間。
- 是否攜帶敵對目標。
- 是否超過承諾兵力或停留期限。

條約失效時，部隊依撤離、扣留、解除武裝或違約規則處理，不瞬間傳回本國。

### 9.3 中立國

中立不代表無主：

- 未經允許越境是主權事件。
- 在中立港口補給需有條款。
- 交戰方不得把中立國當免費安全區。
- 中立國可拘留、驅逐、抗議或選擇參戰。

## 10. 宣戰、戰爭理由與升級

### 10.1 戰爭理由

| 理由 | 常見來源 |
|---|---|
| 自衛 | 本國或盟友遭攻擊 |
| 履行保證 | 條約中的共同防禦 |
| 奪回領土 | 有法理主張或近期被占領 |
| 制止封鎖／破壞 | 持續敵對經濟或情報行動 |
| 解放／復國 | 支援被承認政府或核心人口 |
| 有限強制 | 賠償、通行、解除威脅 |
| 霸權制衡 | 阻止已建立的世界性威脅 |
| 無正當理由 | 仍可宣戰，但承擔較高外交與國內代價 |

戰爭理由影響支持、條款與國際反應，不提供攻擊力加成。

### 10.2 宣戰流程

1. AI 或玩家確立政治目的。
2. 檢查條約、保護、政府權限和國內批准。
3. 建立宣戰訊息及生效條件。
4. 訊息依通信送達。
5. 戰爭狀態生效。
6. 軍事命令仍須集結、行軍與接戰。

偷襲可以讓軍隊先接近或在宣告前發動，但會形成違約、侵略與國際後果；不得繞過玩家新手保護或核心城市警報。

### 10.3 有限與全面戰爭

| 類型 | 目的 | 一般限制 |
|---|---|---|
| 邊境事件 | 驅離、報復、短期控制 | 地域與兵力有限 |
| 有限戰爭 | 特定領土、資源、通行或條款 | 明確目標及退出條件 |
| 聯盟戰爭 | 履行盟約或共同目標 | 盟友責任分開 |
| 全面戰爭 | 政權、附庸、征服或終局 | 高動員、國內與國際代價 |

一場有限戰爭可以升級，但需要新的決策、動員和外交後果。

### 10.4 事件升級

外交危機狀態：

~~~text
摩擦 → 抗議 → 制裁／動員 → 最後通牒 → 敵對 → 戰爭
~~~

不是每次邊境事件都必須走完整鏈，也不因數值跨線自動宣戰。各方可以退讓、仲裁、補償或利用危機。

### 10.5 外交不能規避核心警報

| 模式 | 核心城市最低破壞性攻擊窗口 |
|---|---:|
| 快速 | 2 小時 24 分 |
| 標準 | 6 小時 |
| 史詩 | 15 小時 |

- 宣戰、違約、假旗、代理戰、政變支援或停火破裂，都不能縮短上游最低窗口。
- 最低警報不等於揭露真正責任方；外交指控仍依證據與情報。
- 內部叛亂若將直接破壞核心城市，也必須有等價的可觀察危機階段與反應窗口。
- 同一連續攻勢不因外交狀態反覆切換而重新取得或重設窗口。

## 11. 同盟、保證與共同作戰

### 11.1 同盟不是共用國家

盟友不共享：

- 國庫。
- 部隊控制。
- 全部視野。
- 研究樹。
- 城市與勝利條件。

共享內容必須由條款指定。

### 11.2 防禦條款

需要定義：

- 什麼攻擊觸發。
- 哪些地區受保護。
- 是否包含殖民地、附庸與海外領土。
- 最低援助形式與時限。
- 可接受的例外。
- 不履行的後果。

援助可為軍隊、資源、通行、情報或外交，不一定強制立即全面宣戰。

### 11.3 共同作戰

共同戰爭計畫至少指定：

~~~text
政治目標
各方戰區
預計兵力與物資
指揮協調
通行與補給
情報分享
領土和戰利品
退出條件
~~~

盟軍必須實際通信與行軍，不能共享瞬間命令。

### 11.4 聯盟領導

領導者可以協調目標和提案，不能直接控制其他成員。成員依條約、利益、軍力與國內支持回應。

---

## 12. 附庸、保護國與外交合併

### 12.1 附屬關係

| 類型 | 自治 | 常見義務 |
|---|---|---|
| 朝貢國 | 高 | 定期資源或黃金，有限外交配合 |
| 保護國 | 中高 | 宗主提供防禦，限制部分外交 |
| 自治附庸 | 中 | 貢納、通行、軍事支援與共同敵友 |
| 從屬國 | 低 | 高額義務、外交受限、可逐步整合 |

每種仍由條款組成，不提供固定魔法效果。

### 12.2 建立方式

- 自願尋求保護。
- 戰後和平條件。
- 長期經濟依賴。
- 王位、政治或外交協定。
- 解放後的保護關係。

### 12.3 宗主義務

宗主可能需要：

- 防禦附庸。
- 維持貿易與糧食。
- 尊重自治及領土。
- 不任意徵用超過條款。
- 支援政府存續。

只收貢不保護會降低忠誠並增加獨立意圖。

### 12.4 併吞與整合

附庸轉為直接領土需要：

- 條約或政治同意，或明確強制行動。
- 行政能力。
- 城市整合與文化處理。
- 相應時間、駐軍與國際後果。

不因按下「併吞」瞬間取得滿效率城市。

### 12.5 勝利計算

- 已正式附庸或投降的主要文明可不再阻止征服勝利，前提是世界不存在仍敵對的帝國級政權。
- 一般附庸城市不自動算作宗主直接控制的 1,500 座霸權城市。
- 只有依 City Model 達到有效直接控制與整合條件的聚落才計入宗主城市數。
- 附庸、聯盟或外交網本身不形成第三種勝利。

## 13. 貿易、援助、禁運與封鎖

### 13.1 貿易協定

可以約定：

- 關稅。
- 優先貨物。
- 最低與最高數量。
- 價格或公式。
- 指定市場、港口與路線。
- 戰爭及短缺時的例外。

實體貨物仍依 Economy／World Map 運輸。

### 13.2 援助

援助需要真實：

- 黃金或資源。
- 人員、裝備或部隊。
- 路線、運力和通行。
- 接收方倉庫與行政。

承諾援助不等於已送達。

### 13.3 禁運

禁運只限制本國及受條約約束市場。它可以：

- 降低合法供應。
- 增加價格與替代路線。
- 刺激走私。
- 形成外交壓力。

不能從世界上刪除資源。

### 13.4 封鎖

封鎖需要實際軍隊、船隊、偵察、補給與地理控制。外交命令建立合法狀態，Military／World Map 結算實際攔截率。

### 13.5 走私

走私需要：

- 買賣方。
- 地方網路。
- 真實貨物和運具。
- 未完全封鎖的路線。
- 賄賂、隱蔽及風險。

走私量通常低於公開貿易，可能被查獲並產生政治事件。

---

## 14. 和平、停火與投降

### 14.1 停火

停火要定義：

- 生效時間。
- 停火線和涵蓋部隊。
- 可否補給、撤離、修復及輪換。
- 對被圍城市與海上封鎖的處理。
- 違反事件與查證方式。

命令已在途時，各方需要通信撤回；停火生效不會把飛行中的攻擊或失聯部隊瞬間消失。

### 14.2 談判槓桿

不顯示單一可刷的 Warscore。系統分開評估：

- 政治目標控制。
- 可部署軍力及補給。
- 城市、人口與經濟損失。
- 戰爭疲勞與國內支持。
- 盟友履約及新威脅。
- 封鎖、俘虜及戰略資產。
- 戰爭理由和國際壓力。

玩家從具體原因判斷對方，而不是把分數推到 100 強迫接受任何條款。

### 14.3 和平條款

- 恢復或調整邊界。
- 歸還城市。
- 賠償與分期。
- 交換俘虜。
- 通行、非軍事區和撤軍。
- 承認、自治、附庸或政府保存。
- 解除禁運或封鎖。
- 停戰期限與保證人。

條款不能交付締約方不控制的城市或不存在的資源。

### 14.4 投降

投降可為：

- 地方部隊投降。
- 城市投降。
- 戰區投降。
- 政府有條件投降。
- 政權無條件投降。

範圍不同，剩餘部隊、城市和流亡政府的法律狀態也不同。

### 14.5 戰俘

戰俘具有數量、位置、食物、看守與交換價值。虐待、處決、釋放或交換會影響情報、聲譽、恩怨和國內支持。

---

## 15. 國內政治

### 15.1 政府合法性

合法性 Legitimacy 為 0～100：

| 區間 | 狀態 |
|---:|---|
| 80～100 | 穩固，重大政策仍需成本 |
| 60～79 | 正常，可承受有限失敗 |
| 40～59 | 爭議，政策延遲與反對增加 |
| 20～39 | 危機，政變、分裂與違令風險 |
| 0～19 | 崩解，政府存續受到直接威脅 |

合法性來自制度、履約、民生、安全、勝敗、繼承與核心支持，不是玩家可以直接購買的資源。

### 15.2 主要派系

每個文明通常有 4～6 個聚合派系：

| 派系 | 常見利益 |
|---|---|
| 地方／地主 | 自治、土地、安全、低徵用 |
| 商業 | 貿易、道路、穩定貨幣與開放市場 |
| 軍事 | 國防、軍餉、榮譽、戰略地位 |
| 學術／技術 | 研究、交流、人才與現代化 |
| 城市民眾／勞動 | 食物、工作、住房、公共服務 |
| 傳統／文化 | 身分、制度、核心領土與歷史秩序 |

實際名稱與文明內容可不同，但不能用文化刻板印象決定好壞。

### 15.3 派系資料

~~~text
影響力 0～100
支持度 −100～+100
核心利益
不可接受條件
領導者
控制資產
地區分布
外國聯繫
組織能力
~~~

派系影響政策批准、合法性、地方忠誠與危機，不直接憑空生成資源。

### 15.4 戰爭支持

War Support 0～100 受：

- 戰爭理由。
- 敵方威脅。
- 傷亡、徵兵與缺糧。
- 目標進展。
- 宣傳與可信資訊。
- 盟友與國際支持。
- 政府合法性。

低支持增加徵兵、稅收、違令、談和及革命壓力，不直接讓前線士兵在午夜全體消失。

### 15.5 不可逆政策

大規模徵召、焦土、割地、附庸、政體改變、世界工程、全面戰爭與大規模鎮壓，需要明確批准及後果預覽。有限 AI 攝政不得自行決定。

---

## 16. 忠誠、自治與占領政治

### 16.1 城市資料仍以上游為準

- 忠誠與整合保存在 City Model。
- 抵抗度及駐軍需求沿用 City v0.2。
- 正常和平治理每日整合約增加 3～8。
- 占領收入前 24 小時最高 10%、第 2～3 日 25%、第 4～7 日 50%，完成整合後才依正常政策。

### 16.2 政治政策

占領者可選：

- 軍事管制。
- 地方自治。
- 保留舊官僚。
- 合作政府。
- 文化與法律整合。
- 附庸或保護國。
- 直接吞併。

各方案在安全、收入、整合、國內派系與國際關係間取捨。

### 16.3 鎮壓不是免費穩定

鎮壓需要軍隊、情報、監獄、行政及補給；過度使用可能：

- 暫時降低公開行動。
- 增加長期恩怨和地下支持。
- 傷害人口、繁榮及整合。
- 提高國際威脅與制裁。
- 讓敵方更容易招募抵抗。

### 16.4 自治不是免費收入

自治通常降低短期中央徵收和直接控制，但可提高忠誠、地方治理及長期穩定。

---

## 17. 政變、革命與分裂

### 17.1 風險來源

~~~text
低合法性
+ 派系高影響且強烈反對
+ 軍事敗戰與首都危機
+ 飢荒、失業、過度徵用
+ 文化或自治衝突
+ 外國支援
- 政府安全與反情報
- 民生恢復
- 合法改革與談判
~~~

### 17.2 必須有前兆

玩家可依情報發現：

- 官員不服從。
- 地方稅收或徵兵下降。
- 軍隊忠誠分裂。
- 抗議、罷工、秘密集會。
- 外國金流、武器與宣傳。
- 行省要求自治或領導者更替。

不應從穩定 90 的國家無提示跳出完整叛亂帝國。

### 17.3 危機階段

~~~text
不滿 → 組織 → 政治危機 → 對抗 → 政變／革命／分裂
~~~

每階段都可透過改革、談判、改善民生、替換領導者、自治、反情報或鎮壓處理。

### 17.4 新政權來源守恆

新政權的：

- 人口來自原城市或部隊。
- 庫存來自實際控制、捐助或奪取。
- 軍隊來自倒戈、民兵、外援或已存在地下武器。
- 領土來自實際控制。
- 科技來自原組織、人員與設施。

不能用事件憑空複製原國全部資產。

---

## 18. 領導、繼承與政府更替

### 18.1 領導者死亡或失勢

不會暫停世界。既有：

- 合法繼承規則。
- 緊急政府。
- 政府權限。
- 派系協議。
- 軍隊忠誠。

決定過渡。

### 18.2 更替結果

- 和平繼承。
- 政策轉向。
- 攝政或臨時政府。
- 權力鬥爭。
- 政變。
- 內戰或分裂。

每種結果都保存實際人物、行政、軍隊與城市來源。

### 18.3 玩家控制

玩家扮演文明的戰略意志，不因單一統治者死亡失去存檔。政府更替改變可用政策、成本、派系與外交，但玩家仍控制文明。

---

## 19. 間諜系統原則

### 19.1 間諜不是魔法按鈕

情報行動需要：

- 機構、人員和預算。
- 目標及已知入口。
- 實際旅行或通信。
- 建立資產和掩護。
- 執行時間。
- 傳回資料。
- 暴露與反情報風險。

### 19.2 真相、情報與證據分離

| 層級 | 定義 |
|---|---|
| 真相 | 世界實際發生的內容 |
| 情報 | 某文明相信的估計 |
| 證據 | 可向本國、盟友或世界證明責任的資料 |
| 公開敘事 | 政府或媒體對事件的說法 |

成功破壞但未留下證據，可能只有懷疑；偽造證據可能暫時誤導，但不改寫真相。

### 19.3 情報分類

- 地理與道路。
- 軍隊與補給。
- 經濟與庫存。
- 科技與工程。
- 外交與條約。
- 政府、派系和忠誠。
- 間諜網與反情報。

每項都有來源、時間、可信度、精度與可分享範圍。

---

## 20. 情報機構與網路

### 20.1 情報能力

國家情報能力來自：

- 合法機構與建築。
- 訓練人員。
- 黃金和維護。
- 商路、使館、移民與文化接觸。
- 密碼、通信與科技。
- 盟友分享。

機構受破壞、缺錢或人員流失時能力下降。

### 20.2 目標網路

每個目標文明的 Spy Network 保存：

| 指標 | 範圍 | 意義 |
|---|---:|---|
| 網路強度 | 0～100 | 資產數量、覆蓋及持續能力 |
| 接近權 | 0～100 | 能接觸哪些機構、地區與人物 |
| 隱蔽 | 0～100 | 目標掌握程度及暴露風險 |
| 情報新鮮度 | 0～100 | 最近活動及通信狀況 |
| 反情報壓力 | 0～100 | 搜捕、監控、假資料與雙面間諜 |

### 20.3 建立時間錨點

| 階段 | 標準時間 | 能力 |
|---|---:|---|
| 偵查入口 | 6～12 小時 | 公開與低風險情報 |
| 立足點 | 12～24 小時 | 少量線人與地方情報 |
| 穩定網路 | 24～72 小時 | 可執行中等任務 |
| 深層滲透 | 3～7 日 | 高價值目標，但損失代價大 |

共享文化、商路、使館或占領可縮短；封閉、戰爭與強反情報延長。

### 20.4 網路維護

網路持續消耗黃金、人員、通信和掩護。長期不維護會降低新鮮度與強度，不會永久免費存在。

---

## 21. 情報任務生命週期

### 21.1 七階段

1. 選擇情報需求。
2. 檢查保護、合法權限及目標入口。
3. 準備人員、預算、工具與掩護。
4. 旅行、滲透或建立通信。
5. 執行任務。
6. 撤離、隱蔽或處理暴露。
7. 報告沿合法通信回到決策端。

只有第 7 階段完成後，國家 AI 或玩家介面才取得可用情報。

### 21.2 任務狀態

~~~text
草擬
已授權
準備
滲透
執行
撤離
回報
完成／中止／失敗／暴露
~~~

### 21.3 中止

中止不保證安全返回。已進入目標區的人員仍需撤離，已支付的賄賂、裝備和情報可能損失。

---

## 22. 情報任務類型

### 22.1 蒐集

| 任務 | 可能結果 |
|---|---|
| 地圖偵查 | 道路、橋梁、港口、工事與通行 |
| 軍事情報 | 編制、補給、集結、戰區與可能目標 |
| 經濟情報 | 產地、價格、短缺、運輸與工業能力 |
| 科技情報 | 曝光、原型、研究方向與設施 |
| 外交情報 | 提案、盟約、承諾和內部分歧 |
| 政治情報 | 合法性、派系、領導者與抵抗 |

結果以範圍、時間與可信度呈現，不是永久全圖。

### 22.2 行動

- 竊取文件、樣本或密碼。
- 破壞特定道路、設施、庫存或工程階段。
- 解救、策反或交換具體人物。
- 資助已存在的派系、叛軍或抵抗網。
- 建立假命令、假集結或假外交訊號。
- 協助走私、逃亡、撤離或復國。

### 22.3 不允許的瞬間效果

單次任務不能：

- 直接把一座忠誠城市變成己方。
- 永久刪除已制度化科技。
- 無視時代解鎖工業。
- 讓整支軍隊立刻倒戈。
- 清空遠方國家全部庫存。
- 在沒有網路、人口和武器時生成叛亂。
- 繞過世界奇觀或文明突破硬閘門。

---

## 23. 任務成功、品質與暴露

### 23.1 結果分數

~~~text
任務結果
= 人員能力
+ 網路強度
+ 接近權
+ 情報與準備品質
+ 合法盟助
- 任務難度
- 目標安全
- 反情報壓力
- 時間與通信風險
+ 固定種子不確定值
~~~

不確定值首輪限制在 −15～+15。相同存檔和命令不因重新載入改變。

### 23.2 結果層級

| 結果差 | 任務結果 |
|---:|---|
| +25 以上 | 完整達成，品質較高 |
| 0～+24 | 部分達成或需付額外代價 |
| −1～−24 | 未達成，但可能保持隱蔽 |
| −25 以下 | 失敗且高暴露風險 |

暴露另依隱蔽、任務方式及目標調查判定，因此成功任務也可能留下證據。

### 23.3 暴露層級

| 層級 | 目標知道 |
|---|---|
| 未察覺 | 不知道發生 |
| 異常 | 知道有問題，來源未知 |
| 懷疑 | 有可能責任方及低中可信證據 |
| 識別 | 確認機構或文明，證據可外交使用 |
| 捕獲 | 取得人員、文件或設備，可審訊與交換 |

### 23.4 證據可被質疑

其他文明是否相信指控，取決於：

- 證據品質。
- 提供者可信度。
- 自身情報。
- 既有利益與偏見。
- 反情報鑑定。

世界不自動知道真正幕後者。

## 24. 科技竊取與逆向工程

### 24.1 曝光結果

沿用 Technology v0.2：

- 科技竊取提供約 20～60 曝光或部分研究進度。
- 碎片或短暫觀察提供 5～15 曝光。
- 完整裝備提供 30～50 曝光並可開啟逆向工程。
- 完整裝備、技師及文件提供 50～70 曝光和部分進度。

### 24.2 不跳過條件

竊取仍不能跳過：

- 時代。
- 前置科技。
- 世界奇觀。
- 文明突破工程。
- 大學、工廠、材料和人員。
- 原型、區域採用與全國標準化。

### 24.3 追趕上限

~~~text
追趕折扣
= clamp(
  0,
  0.65,
  0.004 × 曝光度
  + 0.15 × 時代差
  + 授權加成
)
~~~

最低研究時間仍不得低於原最低時間的 50%。

### 24.4 樣本必須運回

實體裝備、文件、技師和樣本依 World Map v0.1 建立貨物或人員批次。途中可能遭查獲、奪回或損壞；只有情報報告可透過通信傳遞。

## 25. 破壞、煽動與欺敵

### 25.1 精確目標

破壞必須指定：

- 一段橋梁、道路或鐵路。
- 一座倉庫、港口、工廠或研究設施。
- 一批物資、樣本或通信設備。
- 一個工程階段或人物。

損害由上游相應系統結算。

### 25.2 破壞代價

- 需要炸藥、工具、內應或存取。
- 可能傷害平民並提高外交後果。
- 設施可以搶修，不因一次成功永久失效。
- 已完成並制度化的知識不會被永久刪除。
- 大型工程有分散、警衛、備份和替代路線。

### 25.3 政治煽動

只能提高已存在矛盾的組織能力、資金、宣傳或信心。若目標：

- 民生穩定。
- 合法性高。
- 派系支持低。
- 沒有武器、領導者或人口。

單靠外國黃金不能直接創造革命。

### 25.4 欺敵

可偽造：

- 假軍隊集結。
- 假路線與補給。
- 假研究方向。
- 假外交提案或文件。
- 假撤退與工程活動。

欺敵要製造可被敵方情報取得的跡象，並承擔被揭穿後的信任和反情報代價。

### 25.5 假旗行動

假旗需要深層網路、高接近權及可驗證素材。若暴露，對使用者的外交傷害通常高於普通破壞。它不能覆寫底層責任記錄。

## 26. 反情報

### 26.1 防禦方式

- 人員審查與分權。
- 設施警衛與區域管制。
- 密碼、通信安全與定期更換。
- 假資料和蜜罐。
- 分散研究、備份檔案和替代路線。
- 調查可疑金流、人物與設備。
- 與盟友交換已確認威脅。

### 26.2 安全與開放的取捨

高強度安全可能：

- 降低間諜成功。
- 延慢研究交流和外交。
- 提高行政與黃金成本。
- 傷害貿易、移民與派系支持。
- 增加錯抓和政治壓力。

不能把反情報拉滿而沒有代價。

### 26.3 雙面間諜

被識別資產可：

- 逮捕。
- 監視。
- 提供假資料。
- 轉為雙面資產。
- 用於交換。

轉化需要人物動機、控制與風險，不是固定成功選項。

## 27. 流亡政府與占領抵抗

### 27.1 狀態承接

沿用 Military／City：

| 狀態 | 條件摘要 |
|---|---|
| 殘存政權 | 首都失守，但仍有城市或成建制殘軍 |
| 流亡政府 | 無受控城市，政府、人員及資產受盟友或中立地庇護 |
| 占領抵抗 | 無受控城市，但有忠誠人口與地下網路 |
| 休眠主張 | 暫無可用軍事來源，文明身分保留 |

### 27.2 流亡政府成立

至少需要：

- 一名合法領導核心或可追溯政府幹部。
- 一個可抵達的庇護地、船舶、軍隊或安全據點。
- 實際通信。
- 最低行政人員和可追溯經費。
- 東道國同意，或在無主安全地以較低能力運作。

流亡政府本身不免費取得城市、軍隊或世界承認。

### 27.3 承認

其他文明可：

- 不承認。
- 非正式接觸。
- 承認其代表人民。
- 承認為合法政府。
- 提供庇護、資源、訓練、情報或軍事支援。

承認影響條約、援助、法理與戰爭理由，不創造資產。

### 27.4 地下抵抗

建立第一個 100 人抵抗分隊沿用 Military v0.1：

| 項目 | 最低需求 |
|---|---:|
| 忠誠人口 | 100 人實際轉出 |
| 武器 | 100 人份或等值隱藏軍備 |
| 食物 | 50 |
| 木材 | 5 |
| 黃金 | 10 |
| 組織時間 | 12 小時 |

大規模起義至少需要抵抗網路 40、人口、武器、通信、可達目標及 24 小時以上準備。

### 27.5 復國

復國入口可以來自：

- 忠誠城市自行解放或叛變。
- 殘軍奪回一座可治理城市。
- 盟軍解放並歸還城市。
- 抵抗起義成功控制城市中心。
- 合法和平條約恢復領土。

取得城市後仍需政府移動、通信、行政重整、糧食、守軍及 City Model 的整合。

### 27.6 休眠主張

若暫無資產，玩家仍可：

- 觀看已知世界。
- 等待已承諾盟助或真實事件。
- 檢視仍可能存在的人口、人物與主張來源。

系統不得提供每日免費復國抽卡，也不能因離線刪除身分。

## 28. 新手保護的外交與情報邊界

### 28.1 時間

| 模式 | 保護 |
|---|---:|
| 快速 | 28 小時 48 分 |
| 標準 | 72 小時 |
| 史詩 | 180 小時 |

### 28.2 允許

- 一般接觸與地圖探索。
- 公開外交、貿易及非軍事通行。
- 教學和強盜等非國家內容。
- 玩家查看情報系統及進行本國反情報。

### 28.3 禁止 AI 對玩家

- 敵對偵察與滲透。
- 科技竊取、破壞、煽動與假旗。
- 封鎖、禁運作為侵略手段或代理攻擊。
- 支援第三方侵略。
- 以條約把玩家強制拖入戰爭。

### 28.4 玩家解除條件

玩家確認下列任一針對政治勢力的命令後，全部保護立即且永久解除：

- 攻擊、掠奪、圍城、占領或封鎖。
- 敵對偵察、間諜滲透、科技竊取或破壞。
- 煽動、假旗、代理支援或協助侵略。
- 參加共同戰爭。

一般外交與貿易不解除。確認畫面必須先列明結果；取消命令不恢復保護。

## 29. 反霸權外交與勝利

### 29.1 威脅形成

反霸權意圖依：

- 可觀察擴張和侵略。
- 世界軍力、人口、經濟的合法估計。
- 關鍵資源、路線和工程控制。
- 條約、恩怨、依賴與距離。
- 世界升級。

同樣適用於玩家與 AI。

### 29.2 霸權危機

任一文明符合 1,500 個有效直接控制聚落、人口第一、軍力第一和經濟第一時，啟動 72 小時危機。

其他文明可：

- 聯盟、宣戰、禁運和封鎖。
- 支援受威脅國、叛軍或流亡政府。
- 加速軍備與科技。
- 談判保障、自治或附庸。
- 保持中立或向霸權靠攏。

每項仍需利益、通信、資產和合法命令。

### 29.3 只有兩種勝利

- 征服。
- 帝國霸權。

聯盟規模、外交聲譽、附庸數、流亡承認、間諜優勢、世界奇觀或文明突破都不單獨形成第三種勝利。

## 30. 玩家有限攝政

### 30.1 可以維持既有外交

攝政可以：

- 履行已簽的定期交付。
- 接受已預先批准範圍內的例行貿易。
- 發送核心城市受攻的盟友求援。
- 執行已簽防禦條約的最低義務。
- 維持現有反情報和撤離。
- 暫停可能危害民生的非必要出口。

### 30.2 不可做

- 宣戰、停戰、永久和平或附庸。
- 割地、併吞或承認新政權。
- 簽永久條約或改變聯盟。
- 啟動敵對間諜、煽動、假旗或破壞。
- 發動復國、起義或跨境反攻。
- 啟動世界奇觀、文明突破或霸權倒數。

### 30.3 到期提案

玩家離線時收到需要不可逆決策的提案：

- 可由預先授權規則接受或拒絕。
- 無授權時標記「等待玩家」，若對方期限到達則自然失效。
- AI 不應故意把所有重要提案期限設在六小時內；期限須符合通信、威脅與事件合理性。

## 32. 玩家資訊與可解釋性

### 32.1 外交卡

至少顯示：

- 關係姿態與六個維度。
- 目前條約、承諾、到期及違約風險。
- 對方公開利益、恐懼和主要恩怨。
- 已知軍事、經濟和政治狀況及可信度。
- 最近重大事件。
- 可用提案和通信時間。

### 32.2 接受／拒絕原因

依合法情報顯示前三項，例如：

> 對方拒絕軍事通行：擔心我方邊境軍力、國內軍方反對、現有中立條約衝突。

不顯示 AI 未被偵察的全部內部權重。

### 32.3 間諜報告

分清：

- 已確認事實。
- 高、中、低信心估計。
- 來源類型。
- 情報時間。
- 可能欺敵或矛盾。
- 何時會快速失效。

### 32.4 警告

割地、宣戰、附庸、全面動員、支援侵略、敵對間諜及解除新手保護必須二次確認，並列出直接後果。

## 34. 系統接口

### 34.1 Economy

- 條約提供貿易、關稅、援助、賠償、貢納和禁運命令。
- Economy 提供真實價格、庫存、支付、交易和履行結果。
- 黃金正常依財政帳戶處理；包圍與通信中斷可能使支付失效。

### 34.2 City

- City 提供忠誠、整合、抵抗、人口、行省和政府所在地。
- Politics 提供自治、占領政策、派系、合法性、分裂和復國狀態。
- 不直接改寫 City 的人口、收入和駐軍公式。

### 34.3 Technology

- Espionage 提供曝光、樣本、文件、專家和破壞事件。
- Technology 決定 RP、時代、前置、最低時間、採用和 65% 折扣上限。
- 世界奇觀與文明突破不可由外交或間諜取代。

### 34.4 Military

- Diplomacy 提供戰爭狀態、政治目標、通行、盟友、停火、投降和俘虜條款。
- Military 提供真實接戰、傷亡、控制和戰果。
- 條約不能讓在途部隊、飛彈或封鎖瞬間消失。

### 34.5 World Map

- World Map 提供國境、通行、使節、間諜、走私、商隊和援軍的實際路線。
- Diplomacy 提供合法通行及違約狀態。
- 情報報告及外交提案在通信送達後才可使用。

### 34.6 AI Civilization

- AI 產生外交、政治和情報意圖、底線及資源包。
- 本模型檢查合法、通信、批准、執行及後果。
- AI 只能取得本模型合法回傳的情報。

### 34.7 Player Experience

本模型輸出：

- 關係與條約摘要。
- 提案、期限、主要原因及後果。
- 國內合法性、派系與危機。
- 情報可信度、證據及暴露。
- 流亡、抵抗與復國入口。
- 新手保護解除警告。

UI 不公開未合法取得的真實資料。

## 35. 驗證案例

### 35.1 關係與條約

1. 高信任但利益衝突不必自動結盟。
2. 高威脅與高依賴能同時存在並產生不同選項。
3. A 信任 B 不會自動讓 B 信任 A。
4. 條約接受舊版本不會套用後改條款。
5. 資源承諾只有在真實送達後算履行。
6. 無能力交付與故意違約得到不同後果。
7. 條約退出通知須送達且等待約定時間。
8. 軍事通行不自動包含商港、領空或永久駐軍。

### 35.2 戰爭與和平

9. 宣戰不讓軍隊瞬間接戰。
10. 偷襲不能繞過新手保護和六小時核心警報。
11. 每場 AI 戰爭具有可結束的政治目的。
12. 停火中失聯部隊依通信處理，不瞬間消失。
13. 和平條款不能交出不受控制城市或不存在庫存。
14. 城市、戰區和政府投降範圍分開。
15. 附庸主要文明可不再阻止征服勝利。
16. 附庸城市不自動計入宗主 1,500 個直接控制聚落。

### 35.3 政治

17. 穩定高合法性國家不會無前兆隨機分裂。
18. 新政權人口、軍隊、資源和科技都能追溯來源。
19. 戰爭支持低不會讓部隊在固定時刻憑空消失。
20. 鎮壓需要資產並具有長期代價。
21. 自治降低直接控制但可改善整合。
22. 統治者死亡不刪除玩家文明。

### 35.4 情報

23. 間諜必須建立網路、旅行、執行並傳回報告。
24. 任務結果不因重新載入重抽。
25. 成功任務仍可能暴露。
26. 目標可知道異常而不知道責任方。
27. 偽造證據不改寫真實責任。
28. 科技竊取只提供 20～60 曝光或部分進度。
29. 追趕折扣不超過 65%，最低時間不低於 50%。
30. 破壞不會永久刪除已制度化科技。

### 35.5 復國

31. 流亡政府需要政府核心、位置、通信和經費。
32. 外國承認不免費生成城市或軍隊。
33. 第一個 100 人抵抗分隊使用真實 100 人、武器、50 食物、5 木材、10 黃金及 12 小時。
34. 大規模起義需要網路 40 及至少 24 小時。
35. 復國取得城市後仍需政府移動和行政重整。
36. 玩家離線時文明不被刪除。

### 35.6 保護、霸權與時間

37. 標準前 72 小時 AI 不能敵對偵察、代理攻擊或煽動玩家。
38. 玩家確認敵對情報行動後全部保護永久解除。
39. 霸權危機維持 72 小時且反制同樣針對 AI 霸權。
40. 外交、附庸、奇觀和間諜不新增第三種勝利。
41. 在線與離線在同世界時間得到相同條約、任務和政治結果。
42. 玩家登入不觸發提案、任務或政變結算。

## 36. v0.1 固定項目與可調項目

### 36.1 本版固定

- 關係由信任、威脅、恩怨、尊重、利益一致及依賴分開構成。
- 外交提案、條約、使節、間諜和情報受通信與世界時間限制。
- 條約效果來自明確條款，資產交付仍需真實庫存和物流。
- 宣戰、停火、投降、附庸、通行與違約具有合法狀態。
- 國內政治使用合法性、派系、戰爭支持和可追溯資產。
- 革命、分裂和復國不生成免費人口、軍隊、領土或資源。
- 間諜網需要人員、預算、入口、時間、通信和風險。
- 情報區分真相、估計、證據和公開敘事。
- 科技竊取、破壞和欺敵不得跳過時代、採用、奇觀與突破。
- 新手保護、有限攝政、六小時核心警報及離線文明存續完全有效。
- 霸權反制同時適用玩家與 AI。
- 正式勝利只有征服與帝國霸權。
- 在線與離線使用相同事件與固定種子。

### 36.2 後續可調

- 關係事件權重與衰減。
- 條約模板、期限、批准時間與擔保方式。
- 派系種類、利益和文明內容。
- 合法性、戰爭支持及革命門檻。
- 情報機構成本、網路建立時間和任務難度。
- 暴露、證據、反情報及欺敵參數。
- 附庸自治、貢納與整合條款。
- 流亡承認與復國的平衡成本。

調整不得破壞第 36.1 節。

## 37. 驗收結論

本模型讓外交不再是單一好感度按鈕，讓政治不再是隨機叛亂，也讓間諜不再是無視地圖的魔法。每項承諾都有條款、傳遞、批准、資產、履行和記憶；每項情報都有來源、時間、可信度與暴露風險。

玩家可以藉由合作、威懾、附庸、停火、情報、自治、流亡承認或復國改變世界，但這些都是征服與帝國霸權路上的手段，不會偷偷增加第三種勝利。

下一份基準為 Player Experience, UI & Notification Model v0.1，負責把持續世界、大型地圖、城市與軍隊管理、外交、情報、六小時警報、有限攝政及離線摘要整理成每天 20～45 分鐘可以理解和下令的玩家流程。
