# City, Population & Building Model v0.3 — 開局、產能與建設節奏

> 2026-09-10，服從 Master v0.4、Economy v0.3。正式修訂；以下取代 [City v0.2](archive/CITY_POPULATION_BUILDING_MODEL_v0.2.md) 的開局、基礎建築工期／費用與預警介面。六級城市人口、升級住房檢查、管理層級、整合／佔領、專業化、奇觀 CP 以及 Day 30 人口配置仍繼承；不能將 Demo 公式直接套用三千萬人口。

## Demo 已實作

- 17 個位置＝城市中心 1＋一般空地 15＋獨立城防 1。新局只有城市中心 L1；城防不是一般空地。
- 先完成農田、伐木場、採石場、金礦各一座，之後民居；再開其他建設及同類資源重複建造。施工中的同種資源也算占用，不能重複排第二座跳過指引。
- 每座資源建築分別計價、計級及產能；其他同類建築每城一座。最高 L5，四資源設施可重複。
- 人口上限＝300＋400×民居等級。每世界小時移入＝36＋12×城市中心等級，中國再 ×1.15；滿住房停止，不刪除超額居民。Demo 這是抽象移民，不宣稱自然出生。
- 每类倉儲＝2500＋2500×倉庫等級。人口不另扣糧；城市中心基礎淨產出已代表地方自給後的可支配額，軍隊另扣。
- 開始建城移出 100 人並實付 350 食、300 木、150 石、150 金；抵達建成，撤回歸還同一批人口，不退開墾物資。
- 每城建造、訓練各 3 格，格數代表等待佇列；兩條各自串行。軍隊動員上限為人口 70%，包含駐軍、訓練與出征承諾。
- 新總督預設每世界小時 2400 四資源合計預算、每類保留 180；舊存檔保留玩家設定。達資源、糧食安全、前置條件後持續補空佇列，會顯示停等原因。保留公共建築空間。總督不替玩家宣戰或研發。
- 個別建築升級浮窗顯示當前與下一級基礎產量、費用、施工與排隊時間；滿級不顯示不存在的六級工程。

各級建築秒數與費用完整列於 [Demo 數值表](BALANCE_v0.7.0.md)，由本版程式內容產生。

## 30 日正式規格修订

1. 開局同樣只有城市中心；原預建農田、林場、採石場與倉庫取消。人口 300，先完成四種資源、民居、兵營。四資源地形在起始區保證可達，不因稀有金礦讓教學卡住。
2. 聚落資源據點上限由 3 提高為 4，其他五級城市仍為 5／8／12／18／24；一般城市槽與資源據點分計。起始一般槽 4 足夠城市中心、民居、兵營與倉庫；其他設施需升級城市或替換用途。
3. 資源 L1 工期 30 秒；L2～5 為 1／2／4／8 分，L6 起 `10分 ×1.26^(L−6)`，L20 約 4 時 14 分。正式學院、市場、倉庫、民居 L1 分別 2／2／1／1 分；基礎兵營 L1 90 秒，其餘以原 L1 建築工期 ×0.75（最少 30 秒）起算。後續用同一資源時間倍率相對 L1 縮放。
4. 建材按 Economy v0.3；新造和升級同式、不得再叠乘舊成本倍率。CP 為該城市基準 CP／時 × 本表工時；實際分配 CP 決定完成速度，不能再加一套固定倒數。普通建築最低驗證時間為本表 25%，避免跨城工程瞬間完工。
5. 城市六級晉升的 2／6／18／48／72 小時工程、住房 115%、世界奇觀和文明突破的兩段大專案保留，不套用普通建築的秒數曲線。
6. 正式人口仍以原自然成長、既有人口移民／合併／佔領為主；民居容量與城市級別沿原表。不可使用 Demo 每城固定加人口公式推到三千萬。
7. 正式總督預算預設按地方可支配淨產出 60% 建設、20% 募兵、20% 保留；玩家可改。缺糧時先投資食物、暫緩募兵。單機不要求定時上線續費、重新委任或領取產量。
8. 城市是否列為核心只影響管理精細度，永遠不再產生六小時無敵警報。
