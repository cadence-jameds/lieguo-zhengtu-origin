# v0.30.33｜B5 戰鬥測試台人工試玩 Checklist

規格 authority：v90。唯一開工 baseline：核對後的 v0.30.32（`a5a975972f793e9e35f1491bd3564f0829204933`）。本輪只新增 B5 人工測試工具。

本表供玩家實機操作，未代填人工 PASS。自動 regression 結果另列於 `regression-tests.json`；桌機／手機 React DOM 操作測試不等同瀏覽器實機試玩。

## 入口與操作

1. 進入既有戰役的「設定」，開啟「開發者模式」。這項既有操作仍會啟用原戰役的資源補滿與加速，請先匯出需要保留的正常戰役備份。
2. 點「B5 戰鬥測試台」。首次會以原戰役的種子與文明建立**新的獨立測試世界**，不是複製原戰役的建設進度。後續開啟讀取上次測試世界。
3. 選 AI 城市、情境、城牆、速度、玩家兵力、守軍與敵城庫存，按「套用／重置測試情境」。修改設定後未重置前，軍令仍對目前已套用的目標；軍令區顯示其名稱。
4. 「玩家測試兵力」為重置時城內兵力；「本次派遣兵力」為這次正式軍令數量。展開兵力列即可編輯，沒有選取情報模式。
5. 「下一行軍／戰鬥事件」推進至下一個正式抵達、返城或征服回合；「＋1 世界分」推進一分鐘。測試世界不會自行走時或離線快轉。
6. 「正式戰報」沿用現有 BattleReports；「測試地圖」可查看正式路徑、目標情報與下達軍令。測試地圖不提供拓殖建城操作。
7. 「存檔重讀」、匯出／匯入 `.b5lab` 都只處理測試進度。「返回原戰役」保留測試進度，原戰役照常走時。

### A. 隔離與重置

- [ ] 開啟測試台後可清楚看到「獨立測試存檔」與金色測試邊框。
- [ ] 正常新局沒有測試守軍、測試庫存或測試戰報。
- [ ] 重置只清空目前測試戰役的在途軍隊、戰鬥與戰報視圖；正常戰役仍保留。
- [ ] 關閉／重新開啟保留測試世界；原戰役繼續自身正常時鐘，不被測試進度替換。
- [ ] 第二個分頁開啟測試台時顯示已有分頁持有存檔鎖，不能建立第二個 writer。
- [ ] 正常存檔不能匯入測試台；`.b5lab` 不能透過正常遊戲匯入取代原存檔。

### B. Raid 掠奪／負重

設定：空城、敵城牆 Lv15、敵城四資源各 10,000；玩家只有民兵10、輜重車1，派出全部。

- [ ] 出征後兵力從城內扣除，顯示路徑、任務、抵達時間與 BattleId。
- [ ] 抵達完成一次掠奪交戰，軍隊進入返程；不改敵城牆、建築或所有權。
- [ ] 戰利品總量大於0，且不超過正式引擎依存活兵力計算的負重。改變輜重車數量重測可比較差異。
- [ ] 戰利品隨軍隊返城，返城後才入庫；四資源庫存為有限數值，不會補回十億。
- [ ] 戰報的存活兵力、四資源戰利品與返程 cargo 一致。

### C. Scout 成功／失敗／反偵察

設定：反偵察斥候（守軍斥候5、民兵30）、敵牆 Lv7，庫存四資源各10,000；每組重置。

- [ ] 玩家10斥候對5反偵察：100 > 60，成功，抵達時保存完整不可變快照。
- [ ] 抵達後尚未返城，目標情報頁與成功戰報仍未交付；下一個返城事件後才顯示。
- [ ] 一次成功即可看到四資源、駐軍／援軍、城牆與合法城防；沒有「資源與軍隊／城防與軍隊」選單。
- [ ] 先推進＋1世界分、重讀，再返城：同一觀測時點與內容仍保留，沒有重新取樣即時庫存。
- [ ] 玩家6斥候對5反偵察：60 = 60，守方勝；攻方斥候全滅、0情報。
- [ ] 玩家1斥候對5反偵察：10 < 60，同樣0情報；其他守軍不遭一般交戰傷亡。
- [ ] 情報標示現實觀測日期／年齡，清楚注明歷史庫存；未洩漏內政、研究、AI決策或出征任務。

### D. 城牆／衝撞車／投石機

設定：空城；敵牆分別 Lv1、Lv7、Lv15，玩家民兵10、衝撞車100、投石機1000；每組先重置再征服。

- [ ] 可以選完整 Lv0～15，其中 Lv0 表示無牆。
- [ ] 征服結果可見城牆下降，戰報列出正式 siege changes；建築／資源田損傷仍由既有 resolver 決定。
- [ ] 相同設定改掠奪時，不造成攻城破壞或易主。
- [ ] 低衝撞車配置（民兵1、衝撞車1、Lv15牆）可驗證城牆仍在時無法直接易主，不為測試台硬判征服成功。

### E. Conquest 多回合／城市易主

可重現配置：敵民兵1000、無牆；玩家民兵2000、衝撞車100，派出全部。亦可改用「混編大軍」比較兵種。

- [ ] 抵達後進入持續交戰，不立即跳過所有回合。
- [ ] 每次推進下一事件，回合數、傷亡與下一回合時間同步更新。
- [ ] 最終戰報 rounds >1；勝利時才由正式征服流程轉移城市所有權。
- [ ] BattleId 不變，round／final ResolutionId 與 receipt 可在測試狀態展開檢查。
- [ ] 沒有改動兵種數值、科技或文明修正；Civilization 衛隊選項與來源文明一致。

### F. 玩家守城

設定：玩家民兵30、牆Lv3。來襲兵力民兵500、衝撞車100、投石機100；兩個任務各重置一次。

- [ ] 「模擬一次敵軍掠奪」由選定敵城所有者發出正式軍令，路徑指向玩家城。
- [ ] 掠奪產生玩家防守戰報，玩家城不易主，守軍／戰利品依正式公式計算。
- [ ] 「模擬一次敵軍征服」可推進多回合與攻城，正式結果允許玩家城戰敗易主。
- [ ] 每個測試情境只允許模擬一次來襲；重讀或倒回舊測試備份不能繞過已記錄的來襲，重置後才可再次執行。
- [ ] 在途任務未完成時禁止注入第二次敵軍；顯示原因，不覆寫交戰兵力。
- [ ] 明確顯示「由你下令，不是AI決策」，沒有新增正式AI自動出兵。

### G. 50X 戰術時間封頂

使用 E 的持續征服配置，分別選50X與200X。

- [ ] 50X：下一回合間隔1,500,000世界毫秒＝25世界分鐘，折合現實30秒。
- [ ] 200X：下一回合間隔6,000,000世界毫秒＝100世界分鐘，折合現實30秒。
- [ ] 介面都顯示「戰術倍率10X」；沒有50X／200X的戰術倍率。
- [ ] 本台為手動事件推進，點按會直接到事件時間；上述現實時間是正式排程換算，不是按鈕必須等待30秒。

### H. 戰報／存讀檔中途接續

- [ ] 出征途中重讀：路徑、出發／抵達時間、BattleId 與兵力相同，沒有消失或重發。
- [ ] 征服第1回合後匯出 `.b5lab`，重讀或匯入後，下個 round event 與 battle pools 保留。
- [ ] 繼續結算只有一筆 final receipt 與一份對應玩家戰報，沒有重複傷亡、資源或易主。
- [ ] 戰報有未讀狀態、現實日期，可讀取、標已讀、清除；目標快照從測試台自己的戰報取得。
- [ ] 手機可展開兵力欄、調整數量、捲動操作；桌機保持同樣功能與正式戰報格式。
