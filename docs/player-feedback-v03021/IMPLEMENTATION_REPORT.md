# v0.30.21｜v85 規格驗證台與單項試玩

本版將開發者模式擴充為可對照 v85 原文、獨立預期值、正式引擎實際值及玩家操作紀錄的驗證台。正常戰役與測試戰役分開；正式規則未在本次調整，B5 尚未開始。

## 玩家試玩方式

1. 進入遊戲「設定 → 開發者驗證 → v85 規格驗證台」。
2. 選擇建築、科技、兵種、時代、高階田或 City／拓殖／物流項目；選擇等級、正例或缺少前置等反例。
3. 按「建立本項試玩情境」，閱讀 v85 預期、操作步驟及完成結果。
4. 到城市／科技／軍隊等實際遊戲頁面操作，也可使用「執行本項正式操作」。兩者均走正式命令與持久化流程。
5. 正例按「下一完成事件」或推進時間，核對扣款、工期、人口及完成結果；反例確認阻擋原因及沒有扣款。
6. 回規格驗證台記錄符合／有問題及備註；匯出驗證報告保留命令、狀態、文明、倍數及試玩設定。

試玩預設暫停，由按鈕推進；正常戰役仍沿用原本持續世界規則。單項結果不能代表所有文明、等級或倍數均已驗收。
