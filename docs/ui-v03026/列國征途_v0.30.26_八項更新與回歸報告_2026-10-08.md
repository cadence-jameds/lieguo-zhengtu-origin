## DEMO 核對

使用既有 v0.30.2 原始碼副本；ZIP SHA256：`39b945b23a74ac6aa75412d31459c3efc7954bde40eb99e766ac33029cc5539a`。

參考 WorldMap.tsx、ReportsView.tsx、messages.ts、CityView.tsx、engine.ts、content.ts。該 DEMO 沒有使用者本次要求的遊戲內開發者控制，因此新控制依使用者指示新增，其保護規則取自 DEMO。

拆除住宅保留現有人口，住房不足時停止成長；拆除倉庫按新容量處理超額庫存並重核入境預約。拆除與取消持續具備 CommandId、event、lane、revision、存檔與 Recovery 一致性。

保護罩有效20世界小時；敵對城市派遣被阻止，抵達及戰鬥中的後續回合停止並撤回。主動對其他領主攻擊或偵察解除自己的保護；野外行動、運輸、增援不解除。金框以較高 CSS specificity 及 z-index 10000 優先於藍框9999。

50X／200X 為開發者覆蓋速度，正常世界 speed 選項及前置保持原規則；征服戰術倍率在兩種速度仍封頂10X。關閉模式後恢復原世界速度並重核倉儲。

## 保存與時間

戰報繼續使用獨立 IndexedDB BattleReports。未讀／清除操作只修改報告表，不改世界 revision／resolution receipts；查詢限定 campaign、玩家、report cursor 與 world time，每頁50則。

新戰報保存 realAt、clockSpeed、read；斥候觀測與結算另保存 observedRealAt／realResolvedAt，避免返程途中變更加速倍率造成時間偏移。野外名稱、座標、資源圖保存快照，避免重生換位後戰報讀取新一代資訊。

舊存檔欄位皆可缺省，原有 checksum 驗證與正式存檔 authority 保留。缺乏現實時間的歷史戰報顯示「時間未記錄」，不猜測舊時間。舊版本仍在返程、尚未保存現實觀測時間的斥候，無法追溯更早版本曾切換的倍率。
