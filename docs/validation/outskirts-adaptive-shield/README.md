# 城郊沿用城內的自動避讓盾牌

基準：最新 main 的 PR #64 合併提交 `3cc66440942581aec2f85de02ce689634662abb8`。玩家明確取消城郊山景固定座標，要求改用城內的顯示方式；本次另開 Draft PR，不直接修改 main。

城內與城郊共用同一條定位流程：從可見場景右下角開始尋位，依實際控制項避讓，限制於場景與 HUD／底部導航之間。城市標題及區域導覽也納入避讓。沒有新增橫列、設定、計時器或每頁元件；其他遊戲頁面的全域盾牌保留，首頁仍不顯示。

窄畫面的邊緣候選點若被佔用，會沿控制項邊界尋找空位。放大後透明資源圖的整個點擊框可能填滿場景；若無法完全錯開，優先保住主要點擊中心，再選擇覆蓋面積較小的位置。沒有更改資源田點擊範圍或任何遊戲規則。
