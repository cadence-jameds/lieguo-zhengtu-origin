# v0.30.1 驗證與更新

2026-10-01，基於正式 v0.30.0 source 9dfafc60bd7eb540fd3e671c83e03c10dcd1ac79。

## 更新

1. 景物快取近景最高 4 倍像素密度，依縮放與 DPR 選擇；高解析圖塊縮小世界範圍，維持 48 MiB 上限。遠景仍使用低解析快取，操作時暫降級，停止後補齊。
2. 地表移除 0.5 倍解析度上限，最高使用 2 倍圖塊。CPU 像素計算交由單一 Web Worker，資料帶入種子與既有城市山體避讓點；過期結果丟棄、失敗時回退同步分批。地表快取維持 96 MiB。
3. 河岸使用使用者允許的原圖直接裁切（RGB 不重繪），柔邊後依種子河道取樣；取消連續雙線。素材來源與製作腳本隨原始碼保存。
4. 標示開關只控制城市名稱；文明簡字、資源種類、資源等級不受開關影響。名稱預設隱藏、保留玩家選擇，最遠景不顯示名稱。

## 驗證

- `npm test -- src/game/mapDisplay.test.ts src/game/terrainWorker.test.ts src/game/painterlyGround.test.ts src/game/sceneryPlacement.test.ts`：4 檔、10 項通過。
- 型別檢查及 `npm run build` 通過。未執行無關完整套件。
- 實際編譯出的地表 Worker 在 Node worker_threads 適配器執行：1408×768 像素產出約 268ms，主執行緒計時器執行 26 次。這是背景計算煙霧測試，不是手機 FPS。
- 用遊戲 Canvas 繪製函式輸出近景、遠景、390×650、最大倍率 2×／DPR2，以及河岸截圖；見本目錄圖片與 render-metrics.txt。
- 遠景景物熱快取約 1.7–2.3ms（一次 8.1ms 離群）；DPR2 最大倍率約 2.2–2.6ms；景物快取約 26 MiB。不是整個遊戲 FPS。
- 未完成手機實機或瀏覽器操作驗證；目前環境沒有 Sites 規定的 control-browser 能力，不使用其他方式繞過該流程。
- 素材仍有原始圖像解析度上限；本次解決快取過度降採樣，不宣稱直接裁切能創造額外像素細節。美術是否符合預期仍由使用者驗收。

## 保留

不變更種子地形、舊城市位置、尋路／建城規則、山體有效遮罩、資源據點背景策略、256×256 格線及向外 50 格渲染範圍。
