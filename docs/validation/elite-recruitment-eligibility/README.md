# 精銳招募資格與現代攻城說明

AI 與總督共用候選保留本來合法的一般兵，直至勢力已完成精銳科技且該城達標。正式募兵替換、價格與在途／在訓兵種未變。現代攻城工程只更新對世界奇觀的既有說明，不更動倍率或情報權限。

聚焦驗證：四類科技、12 個兵種 ID 配對、四種科技及里程碑狀態對照正式募兵成本與入列結果，另用真總督排程驗證普通與精銳兩種狀態。原有奇觀、戰鬥、C9 戰略用例重跑。這不是全量 CI 通過或合併證明。

歷史相容性記錄原封不動。精銳後繼僅接受該次兩個正式來源的精確位元組與限定前代，錯誤前代、任意加字及其他正式檔案仍不在範圍。Android 及 B10 補足後繼證據檢查，保留原有失敗控制。
