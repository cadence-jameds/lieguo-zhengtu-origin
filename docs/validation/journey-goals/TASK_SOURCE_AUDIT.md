## 判定來源與前置

- 建築／資源田：玩家持有期間、原合法指令與正式排程可驗證、正式排程成功完工；只採相應目標等級的完工，不從更高現成建築回推低級任務，不由排程／取消／征服快照發獎。前置直接沿用正式建築表，UI 顯示該表的時代及建築要求；增產建築沿用對應 Lv5 資源田。
- 訓練：玩家合法完成的單位產出，戰鬥兵依既有 effectiveUnit 分類；衛隊須為本文明。持有部隊快照不視為訓練歷史。
- 人口：單城玩家持有期間之權威人口與既有 growPopulation 投影；紀錄實際門檻時點，不合併多城、不依征服前的共用里程碑回推。
- 科技／時代／政治：正式完成的勢力科技與時代、合法軍團／帝國成員狀態。任務分類不是新的硬時代門檻，也沒有任務先後解鎖鏈。
- 偵察：敵城情報的正式 scout-delivery 收據與存活返城交付；掠奪：正式勝利收據、存活軍隊及非零戰利品實際返城。
- 野外／征服／聯軍：正式 resolver 的結算與實際 owner transfer；聯軍另核對正式群組與真實參戰軍隊，保留戰鬥參與者歷史，不依畫面推測，也不新增原規格未要求的參戰支數門檻。
- 拓殖／City／物流／援軍：實體拓殖單位、新城落地與初定、行政工程完成、非零實際送達、正式友軍駐防。自動物流另由排程派遣來源記錄，不相信命令 ID 的 auto 前綴。
- 流亡／外文明城堡：原 resolver 的收編結算及合法工匠團消耗完工；同文明免費城堡不視為 I17。

## 儲存與回復

`growthTasks` 為向後相容的選填世界欄位，舊 metadata／DB 名稱不變。完成與領取紀錄由後端產生；前端只讀已提交任務狀態。可由既有權威資料證明的科技、時代、政治、人口、待命拓殖單位及已抵達商隊在後端初始化。舊存檔中沒有可信歷史證明的建造／訓練／已消失行軍不補造完成事件；之後的合法事件正常累積。

領獎庫存、溢出統計、任務領取 ID 與原指令收據同一 CAS／IndexedDB transaction 提交。戰役 authority 另保留任務不可逆歷史，手動 Recovery／同戰役舊檔匯入不重置已領取 ID；回復庫存不補發獎勵。歷史分支的時間以 growthTasks.recordedThrough 保留，不改世界時間、不影響 B9 倒數。
