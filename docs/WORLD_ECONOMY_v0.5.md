# 河谷 Demo v0.5：獨立領主、資源與城防

本次依玩家核准的提案實作。適用 48 世界小時 Demo（最高城堡時代），不取代 Master v0.3 的完整 30 日世界曲線。仍為單機、同速 AI、瀏覽器本機存檔；不增加服務型遊戲登入獎勵或付費加速。

## 城市與木材

- 0 號城市中心、15 塊一般／既有資源地塊、16 號獨立城防。
- 新戰役每位領主僅有城市中心，其他一般地塊為空，可自由選址。
- 農田、伐木場、採石場、金礦可以重複；每塊地各自等級、工期、費用及施工鎖。科技建築前置讀取同類最高等級，資源產出累計所有地塊等級。
- 城防不占一般空地。修築後顯示完整環城防線；封建木柵、城堡石牆。攻城破壞同步實際等級與外觀，拆除不退建材。
- 建造四種資源建築、再完成第一間民居，才開放其他建設及募兵。三格建造／三格訓練佇列持續使用真實資源。
- 總督先補缺少的基礎建物，不重複安排尚未完工的第一座；基礎完成後優先補兵營、倉庫、學院，再根據方針與庫存／產量找短缺。新增重複資源建築時預留公共建設空間。玩家仍可手動使用合法空地。
- 總督募兵受食物餘裕、人口、建築、預算與最低庫存限制；沒有無成本補兵。

其他資源產量維持：食物 140＋85×農田總等級；木材 110＋95×伐木場總等級；石材 80＋65×採石場總等級；黃金 50＋50×金礦總等級＋15×市場等級，再套整合、文明、方針、科技加成。每名兵力扣 0.6 食物／世界小時。

開局庫存食／木／石／金為 1,200／1,200／800／550。四種資源建築、民居、兵營合計 380／630／330／0；再招五名槍兵並升一次伐木場，共計 583／834／392／20。即使不計等待期間產量，仍餘 617／366／408／530，開局可完成產能與第一支補充部隊。

單座一級伐木場的木材基礎增量提高 26.7%；含城市基礎收入的總木材由 185 提高至 205（＋10.8%，未計文明）。額外伐木場仍消耗土地與材料，不給無限被動收入。

新建 30 世界秒；升二級 2 世界分鐘；升三級起依建築原始工程量，再逐級倍增。介面顯示換算後現實時間。每次升級費用為基礎成本 × 1.55^該地塊目前等級，各資源向上取整。

## 世界與政治

新戰役 168 個據點：36 位獨立領主各一座初始城市、42 處建城遺址、90 個可掠奪 NPC。六文明各六位領主，文明只決定特色與美術；每位領主有自己的領土、庫存、部隊、研究、情報、外交和地圖旗色。

原 18 處中立據點保留，新增 72 個資源營地，四資源各 18 個。新增營地主要資源起始 450，其他各 60；主要資源每世界小時恢復 100，其餘各 15，上限 1,800。兵力初始 3～6 民兵，依六小時營地集結規則恢復。掠奪仍需偵察與行軍，攜帶量受部隊限制，返城才入庫。沒有登入刷新。

AI 正常偵察、建設、募兵、掠奪及拓殖；營地進攻依世界時段分流，避免只反覆打最近營地。軍團不讓 AI 取得玩家城市或資源控制權。

| 操作 | 實際效果 |
|---|---|
| 成立／加入軍團 | 保留各自土地；成員互不侵犯 |
| 邀請 | 團長邀請附近獨立 AI；檢查距離與成員交戰；不自動替玩家加入 |
| 離團 | 土地保留；團長離開時移交團長或解散空團 |
| 請求駐軍援助 | 每六世界小時一次；可用 AI 盟友取自身駐軍的 25%，保留斥候並實際行軍 |
| 援軍到達 | 同團時轉入受援者駐軍並由其供養；關係失效則返程，不複製兵力 |
| 直轄帝國 | 城堡時代、自有八城 |
| 宗主帝國 | 城堡時代、至少一附庸，自己與附庸合計八城 |
| 自治帝國 | 城堡時代、團長、至少三成員且合計八城 |

帝國體制使用目前的直轄／附庸／軍團關係，不額外合併城鎮、產生稅收或部隊。稱帝不直接獲勝。接受臣服時先退出軍團並解除原帝國名號，避免同時隸屬兩個政治體制。正式勝利仍為征服及霸權。

## 時代進度與存檔

- 點城市中心啟動時代升級；頂部 3px 金色細條顯示進度，具可存取的百分比；完成／研究取消後移除，普通科技不占此條。
- v3／v4 舊存檔轉為 schema 5。保留領主、土地、庫存、排程截止時間及已完成科技，不重新分配城市。
- 原城牆及施工中城牆搬到獨立城防；原一般空地釋出。同類既有資源建築保留其等級。
- 36 位領主與新增 NPC 僅用於新戰役。設定頁明確提示舊局與新局的差異，開始另一場前可匯出保存。
- 存檔驗證涵蓋領主與城市參照、地塊、事件、行軍、外交、情報；離線與在線共用事件順序。

## 美術來源

`public/art/town-wall-wood.png`、`town-wall-stone.png` 為本次生成的原創透明 RGBA 圖（1536×1024）：固定等角視角、菱形完整環城防線、透明城內，分別呈現木柵門樓及石牆城門。未使用其他遊戲的原始素材。牆圖不接收滑鼠事件，城防由獨立按鈕開啟。

## 驗證邊界

自動測試包含獨立領主分配、資源建築獨立升級、木材產能、開局預算、總督建設募兵、舊城牆遷移、跨文明軍團、真實援軍、帝國門檻、實際命令的征服流程及六文明 48 小時追算。

整體測試和建置結果以本次交付紀錄為準。自動流程的勝利證明基本路徑可走通，不代表六文明已完成長期平衡。尚未進行本輪真實手機／桌面瀏覽器目視驗收；M6 手動遊玩、實機效能與離線情境仍需試玩回饋，不能將其標為全部完成。

本次驗證結果：13 個測試檔、59 項測試全部通過（含六文明各 48 世界小時完整及切片追算一致性）。原生 TypeScript 檢查通過；追算耗時和存檔量記於 `V0.5_HEADLESS_RESULTS.json`，為 Node 環境數據。

## v0.5.1 首頁與版本辨識（2026-09-08）

每次載入先顯示首頁，讀取完成後按「開始遊戲」接續原存檔；首頁不停止世界追算。首頁、文明選擇、遊戲頂欄及設定都顯示目前載入版本。`public/version.json` 是 UI 與更新檢查的版本來源，檢查請求不使用快取；離線時明確表示無法確認新版本。首頁、進入頁面與每分鐘檢查更新；服務工作執行緒下載完成後顯示保存並更新操作。更新前等待存檔確認，不清除 IndexedDB。
