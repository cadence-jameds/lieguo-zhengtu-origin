# 本輪更新驗證清單（7 項）

1. 載入舊存檔：不再出現「水域城址修正」紀事。
2. 偵察城市／據點：戰報有四種資源、守軍與援軍兵種數量、城牆類型及等級、觀測時間；零庫存顯示 0，未知不當作 0。
3. 未偵察目標：地圖資訊顯示庫存未知。偵察後只顯示當時數值；等待生產或搶掠不會自動更新快照。重生後需重新偵察。
4. 新開局 384 個固定野外槽位，64 區域配額，單區約 4～8 個。糧115、木96、石77、金38、盜賊58（比例採最大餘數法，總數384）。擊破後消失，30＋(Lv−1)×5 世界分鐘後換座標重生。普通資源基礎450，倍率為1/1.35/1.8/2.4/3.1/4/5.1/6.4/7.9/9.6；盜賊 Lv1 合計529並套用相同倍率，守軍增加25%。這是可調基準，尚未宣稱長期經濟平衡完成。
5. 世界地圖回到色塊與地形符號，森林、丘陵、農地仍形成連續地域；地表不再載入貼圖。格線以螢幕解析度繪製，地形快取有每幀工作與96MiB上限。
6. 拖曳到邊界：背景延伸，世界外無可玩格線、不可選取／建城／生成據點。可玩範圍仍256×256。
7. 新開局相同種子、相同版本可重現地形及位置；換種子改變河道方向、彎曲、支流和湖泊。渲染、行軍、水域建城判定採用相同地形版本。
