# Issue #47：軍團／帝國導覽候選，待玩家核准

這是呈現層候選，不是正式發行、規則變更或美術核准。舊版使用同一常數「軍團」；帝國奇觀置於舊軍團五分頁之前，文明突破在奇觀內，帝國管理在軍團管理卡。治理方針已有獨立 view ID，不動。

| 正式投影狀態 | 同一 legion 導覽 ID 的文案 | 內容 |
| --- | --- | --- |
| 尚無軍團 | 軍團 | 現行軍團建立與邀請 |
| 有軍團，尚無帝國 | 軍團 | 現行五分頁、成立帝國 |
| 帝國一般成員 | 帝國 | 帝國總覽、世界奇觀、文明突破、自己的軍團 |
| 帝國成員軍團長 | 帝國 | 上述分頁，另有帝國管理中的軍團退出 |
| 帝國領袖 | 帝國 | 上述分頁，另有邀請、移除所屬軍團、轉讓、解散 |

- 確認玩家實際屬於軍團、軍團指向帝國且帝國同時列出其軍團，再改名稱。不用顏色、名稱或選定城市推測身分。
- 桌面、手機底列、「更多」、自訂清單／移除按鈕皆用同一角色結果。既有快捷只儲存 legion、empire 等 ID，仍最多六格，「更多」位置不變。
- 舊軍團頁完整保留於自己的軍團；重用奇觀和文明突破現有程式，沒有新增／複製建造或輸送規則。治理方針和市場物流保持為原 empire view。移轉領袖、軍團長或切換帝國後重新取得分頁與可見操作，不保留上一個組織的確認視窗。
- 尚未做 320px／390px 和桌面 Chromium 真實版面、地圖奇觀專屬視覺或美術。前者是正式 UX 驗收待辦，後兩者另案，不宣稱 Issue #47 完整結案。不要在玩家 UI 核准前發行。
