# 《列國征途：始源》美術聖經 v1.1

版本：2026-10-28。依本輪玩家授權施工；v1.0 原文完整保留，來源為 Draft PR #43 的 e8a21f8711f6bc349f3d8743385cf1a5a2617256。玩法唯一權威仍為 `docs/b6-v95/河谷戰役_vNext_平衡重構討論_v95.md`。

本版全量繼承 [v1.0](列國征途_美術聖經_v1.0.md) 的資產角色、母圖、色彩、視角、技術契約及 ART-GATE，以下同題新條款優先。

1. 科技正式大卡必須使用 TECH-CARD 具象歷史工藝插畫。`tech-*.svg` 保留為小型 TECH-SYMBOL，不能作新正式大卡的替代品。所有真實 I／II／III 階段各有不同工具與工序；不以相同圖片加羅馬數字代替。只有 I／II 的正式科技不自行新增 III。
2. 兵種按 `unitCatalog.ts` 與 `ELITE_VARIANTS` 的真實關係製作。升階至少武器、護甲、裝備、姿勢其中兩項顯著不同；現代軍事按正式名稱呈現現代裝備，保留共同卡面渲染語言，不把中世紀圖只加「現代」徽章。
3. 四個視覺時代為 0／1／2／3。帝王圖須具更成熟的石造、公共建築與工藝；六文明保留屋頂、服裝與器物特色。純視覺映射不得寫進存檔或更動勢力時代、City 晉升、建築與資源田資格。
4. 施工／升級圖必須呈現未完工結構、鷹架及建材，不以完工圖加符號冒充。排隊與開始施工分開；已完成的現有建築在尚未開始的升級佇列中保持目前外觀。
5. 每張候選須實際把至少兩個同類母圖送入生成器；記錄完整提示詞、來源 SHA256、工具、原始尺寸、裁切 rect、正式輸出及 SHA256。圖集逐格檢查，不能假設生成尺寸和格線符合提示。
6. ART-GATE 十項各 0～2 分，至少 17／20 且角色、視角、技術畫布不得 0。畫面、64px、320／390px 及桌面比對均須有證據；無實測記「待驗」，不以自評代替玩家核准。退件圖保留原始候選與原因，不加入正式映射。
7. **人體與器械結構硬閘門：**第 08 項包含解剖、握持、武器遮擋及機械結構。武器穿過頭盔／臉／身體、手部不能合理握持、車架與輪軸漂浮、拋臂支點／配重／繩索缺乏合理載重路徑，均直接退件，不以其他風格項目高分抵銷。必須看完整尺寸、卡面尺寸及 64px；兵器不得因縮小後不明顯就略過。依玩家本輪指出的投石機與精銳拜占庭騎兵候選缺陷加入本閘門；原候選保留作 FAIL 範例，重製後重評。
8. 已獲玩家明確肯定的視覺元素，應作為局部修正的鎖定項。本輪精銳拜占庭騎兵保留原藍金斗篷、藍色盔纓、金色甲胄、面甲與躍馬姿態，修正武器位置時不得擅自改成另一套紅褐色人物設計。投石車提高木工、鍛鐵包覆與五金工藝品質，不新增遊戲等級或改動數值。
9. **圖集鄰格污染退件：**長槍、弓弦、旗幟、屋頂或其他圖案不得跨格殘留在別張卡面。PNG 可解碼或角落透明不代表裁切合格；必須看每張完整卡面。原兵種圖集的實測橫隔線為 y487，衛隊圖集為 y505；正式元件依量測矩形呈現原 WebP，不重畫母圖。這裡的 SVG viewBox 僅作點陣圖裁切，不是以粗糙向量圖取代正式美術。

本版是本輪美術施工補充，沒有變更 v95／v94 歷史規格、遊戲平衡、ID、存檔或世界規則。Draft PR 可預覽候選整合；最終玩家審查、獨立 Gate 與實體手機驗收各自記錄，不宣稱自動放行。
