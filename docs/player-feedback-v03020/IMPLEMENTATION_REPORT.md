# v0.30.20：B2–B4 開發者驗證與世界地圖全區顯示

## 玩家使用方式

1. 開啟「設定」→「開發者驗證」→進入開發者模式。
2. 按「執行全部自動檢查」，查看每列結果與實際值；再按人工清單各列的「開啟情境」，親自操作並記錄結果。
3. 按「下一完成事件」快速驗證抵達／建造／研究；使用存檔重讀與回復點確認持久化；最後匯出 JSON 驗證報告。

測試戰役使用獨立 IndexedDB，離開後清除測試庫。原戰役沿用原有離線／恢復政策。所有操作都經正式命令、事件排程與保存交易；情境建立時提供資源或資格，不能以此判斷正式解鎖條件已通過。

## 本版功能

- 六種情境：原生 B2、城市經濟、雙城物流、科技軍事、v85 拓殖、D1 現代資格付款。可選六文明、1／3／6／10／50X、種子、人口、時代與城堡等級。
- 測試時間暫停，可按現實秒／分或世界時推進。命令紀錄顯示扣款、人口、單位、事件、佇列和 ledger 的實際前後值。
- 54 項代表性自動檢查：B2 7 項、B3 11 項、B4 32 項、存檔 4 項。包含六文明衛隊限制、各倍數到期時刻、D1 多城科研、v85 400 人／20 護衛／45 秒每格拓殖、取消退款與儲存交易回滾。
- 18 組人工確認清單，依版本、情境、文明、倍數、種子保存筆記；需先開啟對應情境才能記錄該列。切換情境保留最近自動檢查與其設定。
- 程式實際使用的建築、兵種、科技資料可搜尋。資料存在不等同未來戰鬥效果已實作。

## 世界地圖

對照完整 v0.30.2 原始碼的 WorldMap.tsx（SHA256 `9db695ac7d99d4c879ef7c29218d7f376ca034b1f7dcd8420c94ef4210b969f5`）。一般倍率保留原圖示大小公式、野外據點 22% 顯示門檻、政治模式規則及等級顯示條件。原 DEMO 全區固定 13%；384 世界依實際視窗適配全區，手機約 2%。因此小於 12% 改用微型陣營標記，避免城市美術最小尺寸造成巨大圖示。

恢復深綠底、50 格視覺邊界及可遊玩範圍框線。第一畫面直接使用真實 Formal 地形概覽，背景 Worker 再補細節；邊界外只是視覺延伸，不新增可遊玩地塊。拾取與可視範圍依螢幕圖示範圍計算；隱藏的野外據點不可點擊。
